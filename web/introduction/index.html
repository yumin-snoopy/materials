Web入門
Webの仕組みとHTML・CSS・JavaScript

この資料は、授業の最初に「全体像」をつかむためのものです。細かい書き方は、このあと実際に手を動かしながら学びます。

1. Webとは

Webとは、インターネットを使ってページ（情報）を見たり届けたりするしくみのことです。
私たちが普段使っているブラウザ（Chrome、Edge、Safari など）は、次の流れでページを表示しています。

  • ブラウザ：Webページを表示するソフト
  • サーバー：Webページのデータをしまっておくコンピューター
  • URL：ページの住所（例：https://example.com/）

2. Webページは3つの材料でできている

Webページは、HTML・CSS・JavaScript の3つを組み合わせて作ります。家にたとえると、次のようになります。

材料役割家でたとえると
HTMLページの中身・構造柱や壁などの骨組み
CSS見た目（色・大きさ・配置）壁紙・床・家具などの内装
JavaScript動き・しかけ電気・ドアの自動開閉などの設備

3. HTML：中身をつくる

HTMLは、文章に「ここは見出し」「ここは段落」「ここは画像」といった目印をつけるための言葉です。この目印をタグと呼びます。

タグの基本

<タグ名>内容</タグ名>
<p>開始タグ
こんにちは内容
</p>終了タグ
  • 開始タグから終了タグまでで、ひとかたまりです。
  • 終了タグには /（スラッシュ）がつきます。

例

<h1>はじめてのWebページ</h1>
<p>これは段落です。</p>
  • <h1>：大見出し
  • <p>：段落（文章のかたまり）

HTMLだけだと、白い背景に黒い文字の「飾りのないページ」になります。

4. CSS：見た目を整える

CSSは、HTMLで作った中身に色・大きさ・配置などの見た目をつけるための言葉です。

CSSの基本の形

セレクタ {
  プロパティ: 値;
}
  • セレクタ：「どこに」見た目をつけるか（対象を選ぶ）
  • プロパティ：「何を」変えるか（色、大きさ など）
  • 値：「どう」変えるか（赤、20px など）

例

h1 {
  color: red;
}

「h1（大見出し）の文字色（color）を赤（red）にする」という意味です。

セレクタの種類（名前だけ覚えればOK）

種類書き方の例選ぶ対象
要素セレクタpすべての <p> タグ
クラスセレクタ.memoclass="memo" をつけた場所
IDセレクタ#titleid="title" をつけた場所（1か所だけ）

5. JavaScript：動きをつける

JavaScriptは、ページに動きやしかけをつけるためのプログラミング言語です。

  • ボタンを押したら文字が変わる
  • 画像が自動で切り替わる
  • 入力内容をチェックする
  • ゲームや計算ツールを作る

この授業ではまず HTML → CSS を学びます。JavaScript は「こんなことができる」を知っておけば十分です。

6. まとめ

一言で言うと書くもの
HTML中身（何があるか）タグ <p> など
CSS見た目（どう見えるか）セレクタ { プロパティ: 値; }
JavaScript動き（どう動くか）プログラム
