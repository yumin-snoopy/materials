# CSSリファレンス

## 概要

CSSの項目を日本語やプロパティ名で探し、値を変えながら効果を確かめる教材です。

## 主な機能

- CSS項目の検索と説明
- 値を変えた見本とコードの確認
- 値の直接入力・コピー・初期化

## 使い方

左の一覧や検索欄で項目を選びます。値を変えて見本とコードを比べ、必要ならコードをコピーします。

## 起動・体験

[**CSSリファレンスを開く**](https://yumin-snoopy.github.io/materials/web/css_reference/)

## 使用技術

HTML・CSS・JavaScript

## ライセンス・外部ライブラリ

外部ライブラリは使用していません。この教材自体のライセンスは明示されていません。
