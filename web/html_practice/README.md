# HTML5 入力練習ガイド

## 概要

HTMLを1つのファイルに少しずつ手入力して学ぶ教材です。追加するコード、ここまでの全体コード、説明、完成イメージを順に見られます。

## 主な機能

- 学習ステップごとのコードと解説
- 完成イメージと練習問題
- 画像・CSSの教材ファイルのダウンロード

## 使い方

教材ファイルをダウンロードして展開します。各ステップのコードをエディタで入力し、完成イメージと見比べながら進めます。

## 起動・体験

[**HTML5 入力練習ガイドを開く**](https://yumin-snoopy.github.io/materials/web/html_practice/)

## 使用技術

HTML・CSS・JavaScript

## ライセンス・外部ライブラリ

外部ライブラリは使用していません。この教材自体のライセンスは明示されていません。
