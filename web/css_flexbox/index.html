解説

Flexboxの見方

親要素に設定する

子を並べたいときは、子を囲む親に display: flex を指定します。子1つずつに指定するのではありません。

主軸と交差軸

主軸は子が並んでいく道、交差軸はそれと直角の道です。row は横が主軸、column は縦が主軸になります。

2つの位置合わせ

justify-content は主軸の方向に寄せ、align-items は交差軸の方向に寄せます。column にすると、justify-content が上下、align-items が左右を担当します。

gap と margin

gap は並んだ子同士のすき間をまとめて作ります。margin は各要素の外側に付ける余白で、外端にも影響することがあります。

幅が足りないとき

子が入りきらないときは flex-wrap: wrap で次の行へ送れます。横並びは親の幅を、縦並びは親の高さを狭くして確かめましょう。

stretch と baseline

stretch は交差軸に子を伸ばします。高さを固定していると伸びにくいので「auto」にしてください。baseline は文字の下側の基準線をそろえます。
