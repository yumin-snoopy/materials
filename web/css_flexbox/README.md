# CSS Flexbox体験ツール

## 概要

親要素のCSSを変え、子要素の向き・配置・間隔・折り返しを画面で学ぶ教材です。

## 主な機能

- Flexboxの設定と即時プレビュー
- 子要素の数や表示領域の変更
- 5問の練習問題と答え合わせ

## 使い方

まず体験モードで設定を変え、子要素の動きを見ます。練習問題では指示に合う設定を選び、答え合わせをします。

## 起動・体験

[**CSS Flexbox体験ツールを開く**](https://yumin-snoopy.github.io/materials/web/css_flexbox/)

## 使用技術

HTML・CSS・JavaScript

## ライセンス・外部ライブラリ

外部ライブラリは使用していません。この教材自体のライセンスは明示されていません。
