Flexboxの基本を読む

display: flex：親要素をFlexboxにします。子要素が並ぶ出発点です。

justify-content：主軸に沿う並べ方。主軸は、子要素が並ぶ方向です。通常は横方向です。

align-items：交差軸に沿う位置。交差軸は主軸と直角の方向です。通常は縦方向です。

flex-direction：主軸の向きと並ぶ順序を変えます。columnにすると主軸は縦方向です。

flex-wrap：子要素を次の行・列に折り返すか決めます。

gap：子要素の間隔を空けます。例：gap: 24px;
