# シマエナガのCSSレイアウト教室

## 概要

Flexboxの設定を入力し、シマエナガを目標の位置に並べる全20問の学習ゲームです。

## 主な機能

- 20ステージの選択と進捗表示
- CSSを入力して実行・答え合わせ
- ヒント・解答・ステージのリセット

## 使い方

ステージを選び、親要素のCSSにプロパティと値を入力して「実行」を押します。困ったらヒントを確認します。

## 起動・体験

[**シマエナガのCSSレイアウト教室を開く**](https://yumin-snoopy.github.io/materials/web/css_flex_game/)

## 使用技術

HTML・CSS・JavaScript

## ライセンス・外部ライブラリ
