# カラー見本・配色パレット

## 概要

Webページに使う色を探し、背景・メイン・アクセントの3色を組み合わせて試す教材です。

## 主な機能

- 色系統別のカラー見本
- おすすめの3色配色とお気に入り表示
- Webページ見本への反映とカラーコードのコピー

## 使い方

色やおすすめ配色を選び、下のWebページ見本で読みやすさを確認します。使いたいカラーコードを押してコピーします。

## 起動・体験

[**カラー見本・配色パレットを開く**](https://yumin-snoopy.github.io/materials/web/color_palette/)

## 使用技術

HTML・CSS・JavaScript

## ライセンス・外部ライブラリ

外部ライブラリは使用していません。この教材自体のライセンスは明示されていません。
