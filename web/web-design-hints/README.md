# Webデザインのヒント・リファレンス

Web制作授業で、自作のHTML/CSSサイトの見た目を考えるための教材です。

## 使い方

1. index.html をブラウザで開きます。インターネット接続は不要です。
2. 左のメニューからテーマを選び、見本を比較します。
3. CSS例の横にある「説明」ボタンを押すと、意味がポップアップで表示されます。「閉じる」またはEscキーで戻り、コピーしたCSSを自分のページで試します。
4. .cards や .button などのクラス名を使う例は、自分のHTMLにも同じクラス名を付けます。

HTMLリファレンスはタグの書き方、CSSリファレンスはプロパティの意味、CSSデザインサンプルは表現のアイデアを探すときに使えます。この教材は、見本を比較してデザインを選ぶときに使います。

## ファイル構成

- index.html：教材の文章と見本
- css/style.css：教材自体のデザイン
- js/app.js：コピー、ジャンプ率スライダー、メニューの動作
- ../../assets/source-guard.js：リポジトリ共通の閲覧操作の簡易的な抑止
- images/landscape.svg：教材用のオリジナル風景イラスト

## GitHubで公開する前に

ブラウザに表示するHTML、CSS、JavaScript、画像は閲覧者の端末へ配信されます。共通のsource-guard.js は通常の操作を少し抑止するだけで、ソースを秘匿できません。公開GitHubリポジトリではファイルと過去のコミット履歴も読めます。公開したくない内容や秘密情報は、最初からリポジトリや配信ファイルに入れないでください。
