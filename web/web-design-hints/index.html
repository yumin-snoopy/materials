HTML + CSS DESIGN GUIDE

見て、比べて、
自分らしいWebページへ。

レイアウトや色、文字の大きさを少し変えるだけで、ページの印象は変わります。右の見本で違いを確かめながら、使いたいCSSを探しましょう。

この教材の使い方

「どんな見た目にしたい？」から選べる、制作中のヒント集です。

01

見比べる

同じ内容でも、配置や色で印象がどう変わるか確かめます。

02

コピーして試す

各行の意味を読んでからCSSをコピーし、自分のファイルで数値を変えてみます。

03

自分の目的で選ぶ

「読みやすい」「楽しい」など、伝えたい印象に合わせて決めます。

ほかの教材との使い分け： HTMLリファレンスはタグの書き方、CSSリファレンスはプロパティの意味、CSSデザインサンプルは表現のアイデア探しに。このページは、見本を比べて自分のサイトのデザインを決めるために使います。

01

レイアウト

何をいくつ並べるかで、情報の伝わり方が変わります。

カラム

1・2・3カラムを比べる

1カラムは文章をじっくり読ませたいとき、2カラムは画像と説明、3カラムは同じ種類の情報を一覧にしたいときに便利です。

画面が狭いときは、無理に横並びにせず縦に並べます。

2カラムのCSS
.cards {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 16px;
}

このCSSの意味

.cards
このクラス名を付けた要素に、囲まれた指定を適用します。
display: grid
子要素を格子状に並べます。
grid-template-columns
repeat(2, 1fr) は、同じ幅の列を2本作る指定です。1frは空き幅の1つ分。
gap: 16px
カードどうしの間隔を16px空けます。

余白・整列

余白でグループをつくる

関係するものは近づけ、別の内容との間を広げます。内側の余白は padding、外側の余白は margin。並べ方にはFlexboxが便利です。

余白とFlexbox
.item-list {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
  padding: 24px;
}

このCSSの意味

.item-list
横並びにしたい要素を包む親要素のクラス名です。
display: flex
子要素を横方向に並べます。
justify-content: space-between
横方向の両端に要素を寄せ、間を空けます。
align-items: center
縦方向の中心をそろえます。
gap / padding
gapは子要素どうしの間隔、paddingは枠の内側の余白です。

02

配色

使う色をしぼると、ページ全体にまとまりが生まれます。

3つの役割

ベース・メイン・アクセント

ベースは背景など広い面積、メインは見出しや主役、アクセントはボタンなど注目させたい場所に使います。色の面積は「多い・中くらい・少ない」を意識しましょう。

色をまとめて指定
:root {
  --base: #f7f8fb;
  --main: #346c87;
  --accent: #e76f86;
}
body { background: var(--base); }
h2 { color: var(--main); }

このCSSの意味

:root
ページ全体から使える色の変数をまとめる場所です。
--base / --main / --accent
自分で付けた変数名です。#から始まる6桁の値がカラーコードです。
var(--base)
保存した色を呼び出します。1か所の色を変えるだけで、使った場所すべてに反映されます。
body / h2
bodyはページ全体、h2は2番目の大きさの見出しを選びます。

配色例とカラーコード

やさしい・清潔感#f7f8fb / #346c87 / #e76f86
あたたかい・親しみ#fff8ed / #875e45 / #e6994b
落ち着き・自然#f5f7f2 / #3d6854 / #cc735d
さわやか・軽やか#edf8fa / #236b7b / #efad61
上品・やわらか#f8f4fa / #594f79 / #bf6f97
元気・はっきり#fff9e8 / #315b86 / #d95d51
03

ジャンプ率

見出しと本文の文字サイズの差を、目で確かめましょう。

文字の大小

差をつけると、目を引く

ここでは「見出しサイズ ÷ 本文サイズ」をジャンプ率として比べます。差が小さいと落ち着いた印象、大きいと元気で目立つ印象になります。

控えめ大きく
見出しと本文
h2 { font-size: 32px; }
p  { font-size: 16px; }

このCSSの意味

h2 / p
見出しと段落をそれぞれ選ぶセレクターです。
font-size
文字の大きさです。数値を変えると、見出しと本文の差が変わります。
px
画面上の大きさを指定する単位です。ここでは本文16pxを基準にしています。

動かして比較 · 本文は16px

04

文字組み

文字の大きさ、行間、強弱を整えると読みやすくなります。

行間

詰めすぎない、広げすぎない

本文は16px程度から試すと、読みやすさを確認しやすくなります。行間は line-height で調整します。長い文章は行間と横幅も一緒に見てください。

本文の基本
body { font-size: 16px; }
p {
  line-height: 1.8;
  max-width: 65ch;
}
strong { font-weight: 700; }

このCSSの意味

body
ページ全体の文字サイズの基準を指定します。
line-height: 1.8
行の高さを文字サイズの1.8倍にします。単位を付けない書き方です。
max-width: 65ch
文章が長い1行になりすぎないよう、最大幅を制限します。
font-weight: 700
strongで囲んだ文字を太くします。

行間の比較

狭い · 1.1

お気に入りの場所を紹介します。駅から少し歩くと、静かな公園が見えてきます。季節ごとに違う景色を楽しめます。

ゆとり · 1.8

お気に入りの場所を紹介します。駅から少し歩くと、静かな公園が見えてきます。季節ごとに違う景色を楽しめます。

05

画像

形をそろえ、何を伝える画像かも考えましょう。

写真・イラスト

幅と切り抜き方を整える

画像を同じ大きさのカードに並べるときは、aspect-ratio で表示枠の形を決め、object-fit: cover で枠いっぱいに表示します。元の画像と枠の形が違う場合、はみ出た部分は切り取られます。alt には「山と緑の丘のイラスト」のように画像の内容を短く書きます。

画像のCSS
img {
  display: block;
  width: 100%;
  aspect-ratio: 4 / 3;
  object-fit: cover;
  border-radius: 12px;
}

このCSSの意味

display: block
画像の下にできやすい小さな隙間をなくします。
width: 100%
画像を親要素の幅に合わせます。
aspect-ratio: 4 / 3
横4：縦3の形を保ちます。
object-fit: cover
指定した形を埋めるように画像を切り抜きます。
border-radius
画像の角を丸くします。

画像の見せ方

同じ画像でも、表示枠の縦横比を変えると見える範囲が変わります。この見本は教材用のオリジナルイラストです。

06

ボタン

押せる場所だと分かり、言葉で行き先が伝わるようにします。

操作の目印

役割が分かるラベルに

「こちら」だけより「作品を見る」のように具体的な言葉を選びます。別のページやページ内の見出しへ移動するものは <a> です。クリックして説明を開く、CSSをコピーするなど、今見ているページで動作するものは <button> です。この教材の「説明」と「コピー」がその例です。

リンクボタンのCSS
.button {
  display: inline-block;
  padding: 12px 20px;
  color: #fff;
  background: #346c87;
  border-radius: 8px;
}
.button:hover { background: #254f64; }

このCSSの意味

.button
HTMLのリンクなどに付けるクラス名です。例：class="button"。
display: inline-block
文字の流れの中に置きながら、幅や余白を付けやすくします。
padding / color / background
内側の余白、文字色、背景色を指定します。
border-radius
角を丸くします。
:hover
マウスを重ねたときだけ背景色を変えます。

07

見やすさ

見た目の好みと一緒に、読み取れるかを確認しましょう。

読みやすさ

色・幅・強調を確かめる

薄い文字色は背景と重なると読みにくくなります。長い文章は横幅を広げすぎず、大切な情報は色だけに頼らず文字でも伝えます。

読みやすい文字幅
.article {
  max-width: 65ch;
  margin-inline: auto;
  color: #27343b;
  line-height: 1.8;
}

このCSSの意味

.article
文章を包む要素に付けるクラス名です。
max-width
文章の横幅が広がりすぎるのを防ぎます。
margin-inline: auto
左右の外側の余白を自動で分け、中央に置きます。
color / line-height
読みやすい文字色と行の高さを指定します。

08

レスポンシブ

画面の幅に合わせて、無理のない並び方へ。

画面幅

狭い画面では1列に

パソコンでは横に並ぶカードも、スマートフォンでは縦に並べると読みやすくなります。ブラウザの幅を縮めて、文字やボタンがはみ出していないか確認しましょう。

画面幅で切り替える
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
@media (max-width: 700px) {
  .cards { grid-template-columns: 1fr; }
}

このCSSの意味

repeat(3, 1fr)
広い画面では同じ幅の3列にします。
@media (max-width: 700px)
画面幅が700px以下のときだけ、中の指定を使います。
grid-template-columns: 1fr
狭い画面では1列に切り替えます。
gap
列や行の間隔です。1列になってもカードの間隔に使われます。

09

制作の基礎

見た目を整える前に、ファイルと指定の仕組みを押さえましょう。

HTMLとCSS

役割とファイルのつながり

HTMLは見出しや段落など内容の骨組み、CSSは色や余白など見た目を担当します。CSSが反映されないときは、ファイル名と場所を確認しましょう。

HTMLからCSSを読み込む
<link rel="stylesheet" href="css/style.css">

href は、今開いているHTMLから見たCSSの場所です。この例は「cssフォルダーの中のstyle.css」を示します。

セレクター

どこを変えるか決める

CSSの最初に書く名前は、見た目を変える対象を選びます。同じデザインを複数の場所に使うなら、クラス名が便利です。

クラスを付けて選ぶ
<p class="notice">お知らせ</p>
.notice { color: #346c87; }

class="notice" と .notice が対応します。CSSの点 . はクラスを選ぶ印です。

ボックスモデル

余白の場所を見分ける

要素は箱として考えます。内容の周りに内側の余白、枠線、外側の余白があります。幅が合わないときに、この違いが役立ちます。

margin（外側）
border（枠）
padding（内側）内容

box-sizing: border-box を使うと、指定した幅にpaddingとborderを含めて計算できます。

仕上げと公開

表示できるか、使えるか

  • 画像やCSSのファイル名は大文字・小文字まで一致させる。
  • 見出しの順番を整え、画像には内容に合う alt を付ける。
  • マウスがなくてもリンクやボタンを選べるか試す。
  • 使用する写真・イラスト・文章の利用条件を確かめる。
  • スマートフォンとパソコンの両方で表示を確認する。
CHECK

自分のページを、使う人の目線で見直しましょう。

  • 見出しを追うだけで内容が分かる？

  • スマートフォン幅でも横にはみ出さない？
