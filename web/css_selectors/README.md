# CSSセレクター体験ツール

## 概要

セレクターがどのHTML要素に当たるかを、色の変化で確かめる教材です。

## 主な機能

- 要素・クラス・IDなどのセレクター選択
- 一致する要素のプレビュー
- 5問の練習問題と答え合わせ

## 使い方

セレクターを選び、色が付く場所を確認します。練習問題では指示に合うセレクターを選んで答え合わせをします。

## 起動・体験

[**CSSセレクター体験ツールを開く**](https://yumin-snoopy.github.io/materials/web/css_selectors/)

## 使用技術

HTML・CSS・JavaScript

## ライセンス・外部ライブラリ

外部ライブラリは使用していません。この教材自体のライセンスは明示されていません。
