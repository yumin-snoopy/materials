どこにCSSが効くか、見てみよう

CSSセレクター体験ツール

セレクターを選ぶと、CSSが当たる要素だけ色が変わります。

セレクターは、CSSを当てる相手を選ぶ「宛先」です。同じHTMLでも、宛先を変えると色が付く場所が変わります。

練習

どのセレクターを使う？

問題を選び、下の「セレクター」欄で答えてください。プレビューの色も答えの手がかりです。

問題 1

01

セレクターを選ぶ

どのHTML要素にCSSを当てるか選びます。

記号の読み方

p はタグ名、.note の「.」はクラス、#main-title の「#」はIDを表します。

.card p の空白は「cardの中のp」、h2, .note のカンマは「h2とnoteの両方」です。

a:hover は、リンクにマウスを重ねている間だけ当たります。

02

プレビュー

ピンク色の部分が、選んだセレクターに一致した要素です。

サイトの見出し

サイト全体の紹介文です。

記事A

記事Aの説明文です。

記事Aを読む

記事B

記事Bの説明文です。

記事Bを読む

カードの外にある補足文です。

「a:hover」を選んだときは、上のリンクにマウスを重ねてください。

プレビューのHTML構造を見る 
<h1 id="main-title">サイトの見出し</h1>
<p class="intro-text">サイト全体の紹介文</p>
<section class="cards">
  <article class="card">
    <h2>記事A</h2>
    <p>記事Aの説明文</p>
    <a class="demo-link" href="#">記事Aを読む</a>
  </article>
  <article class="card">
    <h2>記事B</h2>
    <p class="note">記事Bの説明文</p>
    <a class="demo-link" href="#">記事Bを読む</a>
  </article>
</section>
<p class="note">カードの外にある補足文</p>
03

CSSコード

選んだセレクターを使ったCSSです。

解説

セレクターの基本

タグ名

p と書くと、ページ内のすべての段落が対象です。同じタグをまとめて整えたいときに使います。

クラス

.note は class="note" が付いた要素を選びます。同じクラスを複数の場所で使えます。

ID

#main-title は id="main-title" の要素を選びます。IDは1ページ内で重複させません。

子孫

.card p は、cardの中にある段落だけを選びます。カードの外の段落には当たりません。

グループ

h2, .note のようにカンマで区切ると、異なる相手に同じCSSをまとめて指定できます。

hover

a:hover は、リンクにマウスを重ねたときだけ当たります。スマートフォンではマウス操作がないので、PCで試しましょう。
