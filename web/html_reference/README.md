# HTMLタグリファレンス

## 概要

HTMLタグの意味や主な属性を調べ、コードと表示結果を一緒に確認できる教材です。

## 主な機能

- タグ名・日本語での検索
- 属性と記述例の表示
- コードの直接編集・表示結果の確認・コピー・復元

## 使い方

タグを選んで説明と例を読みます。コードを書き換えると表示が変わるので、違いを確かめてください。

## 起動・体験

[**HTMLタグリファレンスを開く**](https://yumin-snoopy.github.io/materials/web/html_reference/)

## 使用技術

HTML・CSS・JavaScript
