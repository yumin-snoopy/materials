# Webデザイン練習スタジオ

ボタン、カード、見出し、ナビゲーション、画像付きカードを画面上で編集し、プレビューとHTML・CSSコードを同時に確認できるWeb教材です。ブラウザだけで動作します。

## 主な機能

- 色、文字、余白、幅、枠線、影、ホバーなどの変更
- 5種類の配色プリセットとPC・タブレット・スマートフォン幅のプレビュー
- HTML、CSS、完成コードのコピーとHTMLファイルのダウンロード
- ブラウザ内での保存・読み込み、パーツごとの初期化
- 5問の「お題に挑戦」モード。完成見本、ヒント、答え、許容範囲付きの判定

## 基本的な使い方

1. 「作るパーツ」を選びます。
2. 左側の設定を変更し、右側のプレビューを確認します。
3. 下側に表示されるHTMLとCSSを読んだり、コピーしたりします。
4. 完成したら「HTMLファイルをダウンロード」で単体のファイルとして保存できます。

作業内容の保存先は利用中のブラウザの `localStorage` です。別の端末やブラウザとは共有されません。画像付きカードの画像は、ダウンロードしたHTMLにも埋め込まれるイラストから選択できます。
