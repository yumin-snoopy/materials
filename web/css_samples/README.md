# CSSデザインサンプル集

## 概要

完成見本からWebデザインを選び、対応するHTMLとCSSをコピーできる教材です。12カテゴリ、合計100種類を収録しています。

## 主な機能

- カテゴリ別のデザイン検索
- 完成見本の表示
- HTMLとCSSの個別コピー

## 使い方

カテゴリや検索欄で見本を探します。気に入った見本を開き、HTMLとCSSをそれぞれコピーして自分のページで試します。

## 起動・体験

[**CSSデザインサンプル集を開く**](https://yumin-snoopy.github.io/materials/web/css_samples/)

## 使用技術

HTML・CSS・JavaScript

## ライセンス・外部ライブラリ

外部ライブラリは使用していません。この教材自体のライセンスは明示されていません。
