# CSSデザインサンプル集

Webクリエーター講習向けの、HTMLとCSSだけで使えるデザイン見本集です。

公開ページ: https://yumin-snoopy.github.io/materials/web/css_samples/

## 使い方

1. 左のカテゴリ、検索欄、雰囲気タグからデザインを探します。スマートフォンでは「カテゴリを選ぶ」を開きます。
2. 完成見本を確認し、「HTMLをコピー」「CSSをコピー」を押します。
3. 自分のHTMLファイルにHTMLを、CSSファイルにCSSを貼り付けます。CSSは各見本だけで使えるように書いてあります。
4. 書き方を確かめたいときは「コードを見る」を開きます。

12カテゴリ、合計100種類を収録しています。外部ライブラリ、登録、ログインは不要です。画像装飾の見本には、コピー先でも表示できるように教材独自のSVG画像をHTML内に含めています。画像は自分の写真などに置き換えて使えます。

右クリックや代表的なソース表示ショートカットは、既存教材と同じスクリプトで簡易的に抑止しています。公開されているHTMLやCSSを完全に隠す機能ではありません。
