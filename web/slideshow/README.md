# スライドショー サンプル集

## 概要

画像の切り替え方が異なる10種類のスライドショーを見比べる教材です。各サンプルのソースコードも確認できます。

## 主な機能

- 10種類の切り替え効果
- 各サンプルの再生
- HTML・CSS・JavaScriptのソース表示とコピー

## 使い方

一覧からサンプルを選び、動きを見ます。「ソースを表示」でコードを開き、違いを比べます。

## 起動・体験

[**スライドショー サンプル集を開く**](https://yumin-snoopy.github.io/materials/web/slideshow/)

## 使用技術

HTML・CSS・JavaScript

## ライセンス・外部ライブラリ

外部ライブラリは使用していません。この教材自体のライセンスは明示されていません。
