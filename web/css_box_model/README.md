# CSSボックスモデル体験ツール

## 概要

幅・高さ、余白、枠線などを変え、CSSのボックスが実際に占める大きさを確かめる教材です。

## 主な機能

- 数値や枠線の設定と即時プレビュー
- 実際の表示サイズと模式図の確認
- CSSコードの表示・コピー・初期化

## 使い方

スライダーや数値欄で設定を変えます。プレビューと実際のサイズを比べ、必要なら表示されたCSSをコピーします。

## 起動・体験

[**CSSボックスモデル体験ツールを開く**](https://yumin-snoopy.github.io/materials/web/css_box_model/)

## 使用技術

HTML・CSS・JavaScript
