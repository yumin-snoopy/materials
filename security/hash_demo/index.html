覚えておこう

ハッシュ値は、データの指紋のようなもの

  • ハッシュ値はデータから計算される固定長の値です。
  • 元データが少しでも変わると、ハッシュ値は大きく変化します。
  • 同じデータからは、同じ方式で同じハッシュ値が生成されます。
  • ハッシュ値から元のデータを簡単に復元することはできません。
  • ファイルが改ざんされていないか確認する用途などで利用されます。

改ざん検知・整合性確認に使うには？

配布元のハッシュ値と、受け取ったファイルのハッシュ値を比べます。違えば、データが変わっていると分かります。これが「整合性確認」です。

変更の原因は、改ざんだけでなく、編集やダウンロードの失敗の場合もあります。

異なるデータでも、まれに同じハッシュ値になることがあります。一致だけで安全性をすべて保証できるわけではありません。比較する値は、信頼できる配布元から確認しましょう。
