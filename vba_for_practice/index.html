Forの読み方

  • 開始値、終了値、Step を確認
  • ループごとに変数の値を書く
  • Next の後に Step 分だけ増減する
  • 終了値を越えたらループ終了

Ifと組むとき

  • まず For の回数を数える
  • 各回で If が True か確認
  • True の回だけ処理を反映する
