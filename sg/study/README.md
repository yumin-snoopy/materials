# SG学習トレーナー

[アプリを開く](https://yumin-snoopy.github.io/materials/sg/study/)（GitHub Pages）

情報セキュリティマネジメント試験向けの静的Webアプリです。HTML・CSS・JavaScriptだけで動き、履歴はブラウザの`localStorage`に保存されます。端末間の自動同期はありません。設定画面からJSONのエクスポート・インポート、目標日と文字サイズの変更ができます。

## 収録内容（2026年10月25日確認）

| 種別 | 問題数 | 内容 |
| --- | ---: | --- |
| IPA公式公開問題 | 39問 | 2023〜2026年度の科目A・B公開問題から、4択を忠実に表示でき、解答例と照合できた問1〜12の一部。初期出題対象。 |
| オリジナル 科目A | 300問 | 用語理解を確認するオリジナル問題。公式問題とは区別して出題。 |
| オリジナル 科目B | 20問 | 実務場面を題材にした短い事例問題。公式長文問題とは異なる。 |
| 法律・規格 ○× | 8問 | 個人情報、ISMS、リスク対応について一次資料を確認。 |
| 暗記カード | 9枚 | 個人情報・個人データ・保有個人データ、ISMSと規格、リスク対応。 |

公式問題の本文・選択肢はIPA PDFから取り込み、改行・余分な空白だけを表示用に調整しました。各問に年度、試験区分、問番号、問題冊子、解答例のURLを表示します。解説は本教材のオリジナルです。公式問題の使用に関する[IPAの留意事項](https://www.ipa.go.jp/shiken/faq.html)に従い、出典を明示しています。公式問題の原著作権はIPAにあります。

問題数は公式の公開数です。2023〜2026年度の各年度は実試験60問のうち15問のみ公開されています。[公開問題一覧](https://www.ipa.go.jp/shiken/mondai-kaiotu/sg_fe/koukai/index.html)。2020〜2022年度のSG問題は[IPAの過去問題一覧](https://www.ipa.go.jp/shiken/mondai-kaiotu/)で非公開と明記されているため、公式問題として登録していません。

## 出題・復習

過去問は問題数、出典の種類、分野、年度、未回答、間違い、自信なし、ブックマークで絞り込めます。1回の演習で同じ問題は再出題しません。正誤、回答日時、自己評価、分野、回答回数を保存し、復習では直近の間違い、自信なし、過去の間違い、長期間未回答の順に優先します。正解後も誤答履歴は消しません。

学習時間は直近60秒以内に操作があり、ページが表示されているときだけ15秒単位で計上します。ブラウザの保存データを消すと履歴は失われるため、定期的なJSONバックアップを勧めます。

## 開発・検証

問題データは`data/`内のJSONです。IDは学習履歴との対応に使うため変更しないでください。追加後は次を実行します。

```text
node --check app.js
node validate.mjs
```

`validate.mjs`はID・問題文の重複、選択肢数、空欄、正解範囲、分野、出典、確認日、IPA解答例との対応を検査します。`data/answer_keys.json`はIPA解答例PDFから転記した検証用データです。

法令・規格は[個人情報保護委員会](https://www.ppc.go.jp/all_faq_index/faq3-q2-1/)、[ISMS-AC](https://isms.jp/isms/about.html)、[IPAのガイドライン](https://www.ipa.go.jp/security/guide/sme/ug65p90000019cbk-att/000055520.pdf)を2026年10月25日に確認しました。制度改正があり得るため、受験前に最新の一次資料も確認してください。
