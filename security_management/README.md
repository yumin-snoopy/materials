# SG すきま学習

情報セキュリティマネジメント試験向けの、ブラウザだけで使える短時間学習ツールです。

## 内容

- 用語カード300語：意味・具体例・3段階自己評価
- 科目A向け4択300問：用語の意味と例から選ぶ問題
- 科目B向け短い事例50問：業務上の判断を練習する問題
- 似た用語の比較10組、進捗表示、履歴のエクスポート・インポート

問題文・解説はオリジナルです。実際の試験問題の転載はありません。科目Aの問題は用語理解に重点を置いた基礎問題で、実際の試験の難度や出題形式を完全に再現するものではありません。

## 範囲と更新

2026年10月時点でIPAが掲載する[情報セキュリティマネジメント試験シラバス Ver.4.1](https://www.ipa.go.jp/shiken/syllabus/nl10bi0000007tch-att/syllabus_sg_ver4_1.pdf)の重点分野、関連分野と科目Bの技能項目を参照しました。2026年の制度見直しに伴うシラバス案は確定版ではないため、この教材の基準にはしていません。法律や試験範囲は改訂され得るので、受験前に[IPAのシラバス一覧](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)で最新情報を確認してください。

## 学習履歴

履歴は `localStorage` に保存します。「忘れた」は約10分後、「あやふや」は約4時間後、「覚えた」は連続回数に応じて翌日以降に復習できます。ブラウザの保存データ削除や端末変更で履歴は失われるため、進捗・保存画面からJSONファイルを保存してください。

## データの編集

`terms.json`、`questions_a.json`、`questions_b.json`、`comparisons.json` を編集します。IDを変更すると既存の学習履歴との対応が失われます。変更後は `node --check app.js` とデータ検証を実行してください。
