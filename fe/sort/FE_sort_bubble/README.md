# バブルソート

## 概要

隣り合う値を比べ、大きい値を右へ送る並べ替えを学びます。6個の数値の動きと疑似コードを1ステップずつ確認できます。

## 主な機能

- 1ステップ進む・自動再生・一時停止
- 比較や交換などの回数と疑似コードの表示
- 新しいデータの作成と再生速度の変更

## 使い方

「1ステップ進む」で数値と黄色い疑似コードの行を比べます。流れが分かったら「自動再生」で通して見ます。
