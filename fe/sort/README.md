# ソートアルゴリズム教材

5種類の並べ替えを、数値の動きと疑似コードで比べます。

## 収録内容

| 名前 | 概要 |
| --- | --- |
| [バブルソート](FE_sort_bubble/README.md) | 隣り合う値を比べ、大きい値を右へ送る並べ替えを学びます。 |
| [選択ソート](FE_sort_selection/README.md) | 未整列の範囲で最小の値を探し、先頭へ置く並べ替えを学びます。 |
| [挿入ソート](FE_sort_insertion/README.md) | 値を取り出し、左側の並んだ部分へ挿入する手順を学びます。 |
| [クイックソート](FE_sort_quick/README.md) | 右端の値を基準に左右へ分けて並べる手順を学びます。 |
| [マージソート](FE_sort_merge/README.md) | 配列を半分ずつ分け、順に結合して並べる手順を学びます。 |
