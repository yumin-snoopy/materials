# 基本情報技術者 科目B ソートアルゴリズム

## 目的と対象
科目Bを学習する初心者向けの教材です。どの値を比較し、条件がどう判定され、なぜ値を動かすのかを日本語の説明・アニメーション・疑似コードで対応させます。公式試験問題ではなく、学習用の疑似コードです。

## 使い方
1. fe/index.html または各フォルダの index.html を開きます。
2. 「1ステップ進む」で、説明と強調された疑似コードの行を読みます。
3. 「自動再生」「一時停止」で進行を操作します。速度は3段階です。
4. 「最初から」は同じデータで再開します。「新しいデータを作る」は1～9の値6個を生成します（重複あり）。いずれも自動再生を停止します。

初期値は全教材共通の 7, 3, 5, 1, 8, 4 です。小さい順（昇順）に並べます。位置は0から数えます。オレンジは比較対象、緑は確定位置（挿入では整列済み部分）、紫は最小値候補、ピンクは基準値です。挿入の整列済み部分は、次の値を入れる際に動くことがあります。

## 各教材
- [バブルソート](FE_sort_bubble/)：隣同士を比べて、大きい値を右へ送ります。1周するたび、右端の位置が決まります。
- [選択ソート](FE_sort_selection/)：まだ並んでいない範囲から最小値を探し、その範囲の先頭へ置きます。
- [挿入ソート](FE_sort_insertion/)：左側の並んだ部分に、取り出した値を挿入します。大きい値を1つずつ右へずらします。
- [クイックソート](FE_sort_quick/)：右端の値を基準値にします。基準値以下を左へ集め、基準値の位置を決めたあと、左右の範囲を同じ方法で並べます。
- [マージソート](FE_sort_merge/)：半分ずつ分け、1個になったら結合します。左右の先頭を比べ、小さい値から作業領域に並べます。

クイックソートは右端を基準にした分割方法を使用し、現在の処理範囲・再帰の深さ・次の置き場所pを表示します。マージソートは分割記録を深さ別に表示し、比較した値を作業領域へ書き込んでから元の配列へ戻します。分割記録の値は分割時点の値です。

## 回数の定義
- 比較回数：値同士の大小判定。ループ条件や添字の判定は除きます。
- 交換回数：異なる2位置の値の交換。自己交換は除きます。
- 移動／書き込み回数：挿入の取り出し・ずらし・挿入、およびマージの作業領域と元配列への書き込み。交換とは別の指標です。マージは交換を使わないため交換回数は0になります。

## 構成
各教材に index.html / style.css / script.js を配置。外部ライブラリ・ビルド・サーバー処理なしで動作し、フォルダ単位で配布できます。GitHub Pagesでもそのまま利用できます。PCと教室投影を優先し、狭い画面では疑似コードを下に配置します。
