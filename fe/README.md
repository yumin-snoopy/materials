# 基本情報技術者試験・情報セキュリティ教材

アルゴリズムと情報セキュリティを動かして学ぶ教材です。

## 収録内容

| 名前 | 概要 |
| --- | --- |
| [情報セキュリティ JIS用語検索](CS/readme.md) | 情報セキュリティに関する用語と説明を検索できる教材です。 |
| [配列を調べる基本アルゴリズム](array/README.md) | 配列に入った値を順に調べる処理を、動きを見ながら学ぶ教材です。 |
| [二分探索の可視化教材](array/FE_binary_search/README.md) | 並んだ配列の中央を調べ、探す範囲を半分ずつ狭める二分探索を学びます。 |
| [キューとスタックを動かして学ぶ](fe_queue_stack/README.md) | データを追加・取り出しながら、キューの先入れ先出しとスタックの後入れ先出しを比べる教材です。 |
| [ハッシュ値を比べてみよう](hash_demo/README.md) | 文字やファイルの内容からハッシュ値を求め、少しの変更でも結果が変わることを体験する教材です。 |
| [鍵と証明書の動きを見る](pki_visual/README.md) | 共通鍵・公開鍵・ハイブリッド暗号から、デジタル署名と証明書までを図で学ぶ教材です。 |

| [選択ソート](sort/FE_sort_selection/README.md) | 未整列の範囲で最小の値を探し、先頭へ置く並べ替えを学びます。 |
| [挿入ソート](sort/FE_sort_insertion/README.md) | 値を取り出し、左側の並んだ部分へ挿入する手順を学びます。 |
| [クイックソート](sort/FE_sort_quick/README.md) | 右端の値を基準に左右へ分けて並べる手順を学びます。 |
| [マージソート](sort/FE_sort_merge/README.md) | 配列を半分ずつ分け、順に結合して並べる手順を学びます。 |
