# ハッシュ値確認教材

初心者向けの情報セキュリティ授業で、文字列の変更とハッシュ値の変化を体験するWebアプリです。HTML / CSS / JavaScriptだけで動作します。

## ファイル構成

```text
index.html   画面と教材の説明
style.css    レスポンシブな表示
script.js    ハッシュ計算、差分表示、ファイル確認
README.md    この説明書
```

## 使い方・授業での実演

1. 初期状態は左右とも「情報セキュリティ」です。ハッシュ値の一致を確認します。
2. 「1文字変更してみる」を押します。右側に「。」が1文字追加されます。
3. 多くの桁が変わることを確認します。色と下線は、左右で違う位置を示します。変化する桁数は入力によって変わります。
4. 「元に戻す」を押します。右側が現在の左側と同じ文字列になり、ハッシュ値も一致します。
5. 手入力で空白・改行・大文字と小文字を変えて比べます。入力内容は自動計算されます。空文字も計算できます。
6. ファイルを選択するかドラッグ＆ドロップします。配布元のSHA-256を入力すると一致を確認できます。内容を少し変えて保存したファイルでも比較してみましょう。

「元に戻す」は左側を初期値に戻すボタンではありません。「1文字変更」は押すたびに右側の末尾へ「。」を追加します。リロードすると初期状態に戻ります。

## GitHub Pagesで公開する手順

1. この4ファイルを公開用GitHubリポジトリの `fe/hash_demo/` にアップロードし、コミットします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment → Source** で **Deploy from a branch** を選びます。
4. アップロードしたブランチ（通常 `main`）と **/ (root)** を選び、保存します。
5. Pagesのデプロイ完了後、表示されたHTTPSの公開URLを開きます。
6. 一致 → 1文字変更 → 不一致 → 元に戻す → 一致の順に確認してください。

この教材はFE情報セキュリティ教材として `fe/hash_demo/` に配置します。

## ローカルで確認

Web Crypto APIが利用できるHTTPSまたはlocalhostで開いてください。ローカルサーバーを利用できる場合は、ファイルのあるフォルダーで `python -m http.server 8000` を実行し、`http://localhost:8000` を開きます。ファイルを直接ダブルクリックした場合の動作はブラウザによって異なります。

## 計算とプライバシー

- 初期方式はSHA-256（64桁 / 256ビット）。SHA-1は40桁、MD5は32桁です。
- SHA-256 / SHA-1はWeb Crypto APIを利用します。MD5は同APIの対象外のため、学習用JavaScript実装を利用します。
- SHA-1 / MD5では「現在はセキュリティ用途では推奨されない方式です」と表示します。
- 文字列はUTF-8で計算し、空白・改行を除去しません。Unicodeの正規化も行いません。見た目が同じでも、内部のデータが違えばハッシュ値が変わる場合があります。
- ファイルは名前ではなく内容のバイト列から、常にSHA-256を計算します。空ファイルにも対応します。メモリ使用を抑えるため1回に1ファイル、50 MBまでです。
- データはブラウザ内だけで処理します。アプリによるAPI通信、アップロード、解析ツール、外部ライブラリ、外部フォント、入力の保存はありません。Pagesから画面のHTML / CSS / JavaScriptを取得する通信は発生します。
- 同じハッシュ値だけで安全をすべて保証することはできません。比較する値を信頼できる配布元から取得することが大切です。ハッシュ値の違いだけでは、改ざんか通常の編集かは区別できません。

## 表示・アクセシビリティ

PCは左右2列、幅720px以下では上下1列です。差分は色に加えて下線と文字数で示します。操作にはキーボードも使え、比較結果は読み上げ用の通知エリアに表示します。
