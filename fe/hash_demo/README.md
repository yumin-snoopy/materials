# ハッシュ値を比べてみよう

## 概要

文字やファイルの内容からハッシュ値を求め、少しの変更でも結果が変わることを体験する教材です。

## 主な機能

- 2つの文字列のハッシュ値比較
- SHA-256・SHA-1・MD5 の学習用比較
- ファイルの SHA-256 と配布元の値の照合

## 使い方

左右の文字列を変えてハッシュ値を比べます。ファイルを調べる場合はファイルを選び、必要なら配布元のハッシュ値を入力します。

## 起動・体験

[**ハッシュ値を比べてみようを開く**](https://yumin-snoopy.github.io/materials/fe/hash_demo/)

## 使用技術

HTML・CSS・JavaScript

## ライセンス・外部ライブラリ

外部ライブラリは使用していません。この教材自体のライセンスは明示されていません。SHA-1 と MD5 は学習用の比較対象で、セキュリティ用途では推奨されません。
