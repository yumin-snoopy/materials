# 情報セキュリティ JIS用語検索

## 概要

情報セキュリティに関する用語と説明を検索できる教材です。CS検定シラバス掲載用語には「CS」マークを付けています。

## 主な機能

- 用語の検索
- CS検定シラバス用語だけの表示
- 用語の説明表示

## 使い方

検索欄に知りたい言葉を入力します。CS検定の用語に絞りたいときは、専用の表示切り替えを使います。

## 起動・体験

[**情報セキュリティ JIS用語検索を開く**](https://yumin-snoopy.github.io/materials/fe/CS/)

## 使用技術

HTML・CSS・JavaScript

## ライセンス・外部ライブラリ

外部ライブラリは使用していません。この教材自体のライセンスは明示されていません。
