# キューとスタックを動かして学ぶ

## 概要

データを追加・取り出しながら、キューの先入れ先出しとスタックの後入れ先出しを比べる教材です。

## 主な機能

- 両方に A・B・C を入れる比較
- 追加・取り出し・リセット
- 取り出し順と操作履歴の表示

## 使い方

「A → B → C で比較」を押すか、それぞれの追加ボタンでデータを入れます。取り出しボタンを押して、出てくる順番を比べます。

## 起動・体験
