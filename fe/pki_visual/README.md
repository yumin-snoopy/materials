# 鍵と証明書の動きを見る（PKI視覚教材）

## 目的・対象

基本情報技術者試験（FE）の情報セキュリティを学ぶ初心者向けの、授業用Web教材です。講師が1段階ずつ操作し、鍵や証明書の動きを説明できます。

## 学習できる内容

- 共通鍵暗号方式と公開鍵暗号方式の違い、鍵配送問題
- ハイブリッド暗号方式での鍵共有とデータ通信の役割分担
- SHA-256、秘密鍵によるデジタル署名、公開鍵による検証と改ざん検出
- デジタル証明書、認証局（CA）、公開鍵基盤（PKI）の関係
- 5問のミニクイズ

## 操作方法

上部のボタンで4つの学習モードと「ミニ問題」を切り替えます。問題は「ミニ問題」を押したときだけ表示されます。「次へ」「戻る」「最初から」で説明を1段階ずつ進めます。暗号方式の比較とハイブリッド暗号では、各人物のカード内にその時点で持っている鍵を表示します。署名モードでは文章を入力して「デジタル署名を作成」→「受信側で確認」→「文章を改ざんしてみる」→再確認の順で試します。問題は選択肢を押すと正誤と解説が表示されます。

共通鍵暗号方式・公開鍵暗号方式・ハイブリッド暗号方式では、「こんにちは」という平文が暗号文に変わり、受信者の復号で元に戻る様子を段階表示します。表示する「Q7x-9mP」は暗号文の見た目を示す例であり、実際の暗号化結果ではありません。

署名体験はWeb Crypto APIのSHA-256とRSA-PSSを使用します。デジタル証明書とCAは学習用の模式図であり、実際の証明書発行やブラウザの検証処理は行いません。現在のTLSでは、共通鍵を公開鍵で直接暗号化して送るよりも、鍵共有で共通鍵を作る方式が一般的です。
