# 鍵と証明書の動きを見る

## 概要

共通鍵・公開鍵・ハイブリッド暗号から、デジタル署名と証明書までを図で学ぶ教材です。表示は学習用の模式図です。

## 主な機能

- 暗号方式の比較
- ハイブリッド暗号・署名・証明書の段階表示
- 確認用のミニ問題

## 使い方

上部の学習項目を選び、「次へ」で1段階ずつ進めます。最後にミニ問題で内容を確かめます。

## 起動・体験

[**鍵と証明書の動きを見るを開く**](https://yumin-snoopy.github.io/materials/fe/pki_visual/)

## 使用技術

HTML・CSS・JavaScript
