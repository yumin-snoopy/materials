# 二分探索の可視化教材

## 概要

並んだ配列の中央を調べ、探す範囲を半分ずつ狭める二分探索を学びます。比較する位置と残る範囲を画面で確認できます。

## 主な機能

- 中央の値との比較を段階表示
- 探索範囲と処理の説明表示
- 最初からのやり直し

## 使い方

探す値を確認してから、画面の操作ボタンで処理を進めます。中央との比較後に、どちらの半分が残るか見てください。
