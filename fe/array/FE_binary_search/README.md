# 二分探索（Binary Search）可視化教材

## 目的と仕組み

基本情報技術者試験（FE）向けに、中央の値と探す値を比較し、不要な半分を探索対象から外す流れを1ステップずつ示します。`low` は左端、`high` は右端、`mid` は中央のインデックスです。`mid = floor((low + high) / 2)` で求め、小数点以下を切り捨てます。

## 操作

「探す値」に整数を入力して「検索開始」を押します。「1ステップ進む」で中央の計算、比較、範囲更新を順に確認できます。「自動再生」は約1秒ごとに進み、「一時停止」で止まります。「最初から」は同じデータの初期状態に戻し、「新しいデータを作る」は重複しない9個の整数を昇順に並べます。検索値を変えたら「検索開始」を押してください。

## 線形探索との違いと条件

線形探索は先頭から1つずつ確認します。二分探索は中央を確認し、不要な半分を除外します。同じ値について両方の比較回数を画面に表示します。ただし、二分探索にはデータが昇順または降順に並んでいることが必要です。この教材は昇順専用です。並び替えていないデータでは、中央より小さい値が右側にある可能性があるため、片側を安全に除外できません。

## GitHub Pages

このフォルダの4ファイルを `fe/array/FE_binary_search/` に配置すると、`https://yumin-snoopy.github.io/materials/fe/array/FE_binary_search/` で利用できます。`index.html` を直接開いても動きます。外部ライブラリ、サーバー通信は不要です。

`index.html` は読み込みと画面の土台、`style.css` は表示、`script.js` は教材の描画と操作、`README.md` は説明です。共通の `../../../assets/source-guard.js` で右クリック・F12・Ctrl/Cmd+Shift+I/J/C・Ctrl/Cmd+Uを抑止し、この教材の `script.js` でCtrl/Cmd+Sも抑止します。これらは通常のブラウザ操作を難しくする簡易対策であり、ソース保護や開発者ツールの完全禁止はできません。
