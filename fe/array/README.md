# 配列を調べる基本アルゴリズム

## 概要

配列に入った値を順に調べる処理を、動きを見ながら学ぶ教材です。最大値・最小値・合計・平均・線形探索を扱います。

## 主な機能

- 処理を1ステップずつ表示
- 最大値・最小値・合計・平均・線形探索の比較
- 配列と説明の表示

## 使い方

教材を開き、学びたい処理を選びます。ボタンで1ステップずつ進め、どの値を調べているか確認します。
