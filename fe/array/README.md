# FE アルゴリズム可視化教材 — 配列を調べる基本アルゴリズム

基本情報技術者試験（FE）科目Bに必要な「配列を先頭から順番に確認する」考え方を学ぶ、教育用途のWeb教材です。

## 収録アルゴリズム

- 最大値・最小値：順番に比較し、必要なときに値を更新
- 合計：`sum ← sum + data[i]`
- 平均：すべての要素の合計を求めてからデータ数で割る
- 線形探索（順次探索）：入力した値を先頭から探し、最初に見つかった位置で終了

## 操作方法

1. 上部のボタンでアルゴリズムを選択します。
2. 「1ステップ進む」で、初期化・比較・更新・終了を順番に確認します。色の付いた疑似コード行と日本語の説明が連動します。
3. 「自動再生」は約1秒間隔で進みます。「一時停止」で止め、手動で続けられます。
4. 「最初から」で同じデータを繰り返し学べます。表示数はコンボボックスで5～9個から選べます（初期値7個）。個数を変えると新しいデータで最初から始めます。「新しいデータを作る」は選択中の個数を維持し、1～20から重複しない整数を選びます。
5. 線形探索では「探す値」に整数を入力します。変更すると先頭からやり直します。インデックスは0から始まります。

平均の小数は最大4桁まで表示します。割り切れない計算式には「≈」を表示します。タブを非表示にすると自動再生は一時停止します。

## GitHub Pagesでの利用

このフォルダ全体を教材用リポジトリに配置し、GitHubの Settings → Pages で公開元のブランチとフォルダを設定してください。既存のPagesを使う場合は、現在の公開元にこのフォルダを追加するだけで利用できます。

公開URL：`https://yumin-snoopy.github.io/materials/fe/array/`

ローカルでは `index.html` をブラウザで開くこともできます。外部ライブラリ・サーバー処理・データ送信は不要です。

## ファイル

- `index.html`：最小限のページ構造とCSS・JavaScriptの読み込み（改行・空白を圧縮）
- `style.css`：カード・操作ボタン・疑似コード・レスポンシブ表示
- `script.js`：画面生成・5種類の処理・ステップ操作・自動再生・検索入力
- `README.md`：教材の目的と利用方法

右クリックメニューを無効にしていますが、完全なソースコード保護ではありません。F12や代表的な開発者ツール／ソース閲覧のショートカットを抑止しますが、完全には禁止できません。共通の `../../assets/source-guard.js` が必要です。CSS・JavaScriptは修正しやすい形を維持しています。
