# ワークフロー型と自律型AIエージェントの比較デモ

生成AIパスポート講習向けの非公式教材です。同じ「週末の1泊旅行を予算5万円以内で計画する」という依頼で、次の手順の決め方を比較します。

## 使い方

`index.html` をブラウザーで開きます。インターネット接続は不要です。「次のステップへ」を順に押し、ワークフロー型と自律型を切り替えて比べてください。最初の候補が予算を超える例と、予算内に収まる例を選べます。

## 説明の要点

- ワークフロー型は、人が事前に設定した手順と条件分岐に従います。予算超過時も、設定済みの「宿を再検索」へ進めます。
- 自律型AIエージェントは、目標や状況に応じて次の作業をAI自身が判断します。デモでは「交通を見直す」と判断する想定を示します。
- 画面内の金額・候補・AI判断は架空の固定シナリオです。LLM・旅行検索・外部APIは使いません。自律型の実際の推論能力を再現するものではありません。

授業では、まず予算超過の例を両方式で最後まで実行し、次に予算内の例で「どちらも追加の見直しが不要」であることを確認できます。

## 構成

- `index.html`：HTML、CSS、JavaScriptを含む単体ファイル。外部ライブラリ・画像・フォントへの依存なし。
- `README.md`：この説明。

公開サイト上では `AI_Passport/agent_workflow_demo/` から開ける想定です。単体ファイルを配布する場合は `index.html` だけで動作します。ページ下部の用語ノートへのリンクは、単体配布時には参照先が存在しないため利用できません。
