# ワークフロー型と自律型AIエージェントの比較デモ

生成AIパスポート講習向けの非公式教材です。同じ「週末の京都1泊旅行を5万円以内で計画する」という依頼に、満室、雨、交通遅延、運賃値上がり、同行者の希望変更を順に起こして比べます。

## 使い方

`index.html` をブラウザーで開きます。インターネット接続は不要です。「1ステップ進める」を押し、変化の直前で「発生させる」を押します。両方式を並べるか、片方だけを大きく表示するか切り替えられます。「最初から」で授業をやり直せます。ページは縦にスクロールします。

## 説明の要点

- ワークフロー型も、設計済みの条件分岐・再試行で満室、雨、遅延、予算超過を処理します。歩行距離を短くする希望は未登録なので、人に判断と設計変更を依頼して完成を保留します。
- 自律型は目的、模擬ツール、安全条件の範囲で、状況の把握、行動の選択、ツール実行、結果の検証、計画変更を繰り返す想定です。最後は徒歩を抑えた5万円の確認用の案を提示します。
- 各ステップの「次の行動を決めたのは」と「結果を受けて変えたこと」に注目します。同じ結果になる場面もあり、違いは常に成果の優劣ではありません。
- 金額、空室、天気、運行情報、ツール結果、AIの判断は架空の固定シナリオです。実際のAI・予約・決済・検索・外部APIは使いません。実際のAIは誤る場合もあるため、人による案の確認が必要です。

## 構成

- `index.html`：HTML、CSS、JavaScriptを含む単体ファイル。外部ライブラリ、画像、フォントへの依存なし。
- `README.md`：授業用の説明。

公開サイトでは `AI_Passport/agent_workflow_demo/` から開けます。単体配布では `index.html` だけで動作します。
