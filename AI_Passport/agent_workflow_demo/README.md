# ワークフロー型と自律型AIエージェントの比較デモ

生成AIパスポート講習向けの非公式教材です。同じ「週末の1泊旅行を予算5万円以内で計画する」という依頼で、次の手順の決め方を比較します。

## 使い方

`index.html` をブラウザーで開きます。インターネット接続は不要です。「1ステップ進める」を順に押すと、両方式が同時に進みます。方式ごとの拡大表示にも切り替えられます。最初の候補が予算を超える例と、予算内に収まる例を選べます。

## 説明の要点

- ワークフロー型は、人が事前に設定した手順と条件分岐に従います。予算超過時も、設定済みの「宿を再検索」へ進めます。この例の固定ルールには追加の希望を組み込んでいません。
- 自律型AIエージェントは、目標や状況に応じて次の作業をAI自身が判断します。デモでは、温泉宿を優先するなら交通を、移動手段を優先するなら宿を見直す想定を示します。
- 画面内の金額・候補・AI判断は架空の固定シナリオです。LLM・旅行検索・外部APIは使いません。自律型の実際の推論能力を再現するものではありません。

授業では、まず「温泉宿を優先」の予算超過例を両方式で同時に実行します。③の分岐で、ワークフロー型は固定ルール、 自律型は複数の候補を比べる想定であることを確認します。次に希望を「移動手段を優先」へ変え、ワークフロー型の動きは変わらず、自律型は別の選択になることを示せます。どちらも同じ行動になる場合もあります。また、人が追加の希望に応じた分岐を事前設定すれば、ワークフロー型でも別の行動を取れます。

## 構成

- `index.html`：HTML、CSS、JavaScriptを含む単体ファイル。外部ライブラリ・画像・フォントへの依存なし。
- `README.md`：この説明。

公開サイト上では `AI_Passport/agent_workflow_demo/` から開ける想定です。単体ファイルを配布する場合は `index.html` だけで動作します。
