# 生成AIパスポート 用語ノート

[用語ノートを開く](https://yumin-snoopy.github.io/materials/AI_Passport/)

生成AIの用語を、やさしい意味・具体例・覚えるポイントで調べる非公式の学習教材です。

- 章やテーマで絞り込み、英字・カタカナ・ひらがなで検索できます。
- 「あとで復習」の印を、利用した端末・ブラウザーに保存します。
- 表示中の用語を印刷し、ブラウザーからPDFに保存できます。
- 各項目に、公式ドキュメントなどの参考リンクを掲載しています。

説明と具体例は本教材用に書き起こしています。教科書の本文・図・問題は転載していません。
試験範囲の確認には、[GUGAの公式シラバス](https://guga.or.jp/assets/syllabus.pdf)をご利用ください。

## ファイル

- `index.html`：用語とページ構成。用語は `article.term` の単位で追加できます。
- `style.css`：画面・印刷の見た目。
- `app.js`：検索・絞り込み・復習マーク・印刷の操作。
- `../assets/source-guard.js`：右クリックと主なソース表示・開発者ツールのショートカットの簡易抑止。

ソース閲覧の完全な禁止を保証するものではありません。
