2. ChatGPTとは

ChatGPTは、OpenAIが開発した自然言語処理モデルを使った対話型AIです。 人間と会話しているような自然なやり取りができる点が特徴です。

文字 意味 説明
Chat 対話型 質問に対して文章で返すだけでなく、会話の流れを踏まえて応答する。
G Generative：生成 文章、要約、アイデア、コードなどを新しく作り出す。
P Pre-trained：事前学習済み 大量の文章データであらかじめ学習している。
T Transformer 文章中の単語同士の関係を見ながら処理するAIモデルの仕組み。

たとえで理解

ChatGPTは「大量の本や文章を読んで、次に来る言葉や自然な返答を予測できるようになったアシスタント」 と考えるとわかりやすいです。ただし、本当に意味を人間と同じように理解しているわけではなく、 学習したパターンをもとにもっともらしい文章を生成します。

3. 試験で押さえる重要語句

この章の学習ポイント

ChatGPTの仕組みを理解するうえで重要なのは、 「AIがどのように言葉を扱うのか」「なぜ人間らしい回答ができるのか」 「なぜ間違えることがあるのか」を、用語とセットで理解することです。

試験では、単語の丸暗記だけでなく、 意味・具体例・似た用語との違い が問われやすいので、以下の用語を丁寧に押さえましょう。

① 自然言語処理（NLP）

自然言語処理（NLP：Natural Language Processing）とは、 人間が普段使っている言葉、つまり日本語や英語などの 自然言語をコンピュータに処理させる技術です。

たとえば、私たちは「明日の予定を教えて」と自然に話します。 このような文章をAIが読み取り、意味を推測し、適切な返答を作るために使われるのが自然言語処理です。

具体例

  • 文章を要約する
  • 日本語を英語に翻訳する
  • 質問に答える
  • メール文を作成する
  • 文章の誤字脱字を修正する

試験ポイント

ChatGPTは、自然言語処理を活用した対話型AIです。 NLPは「人間の言葉をAIが扱うための技術」と覚えましょう。

② データセット

データセットとは、 AIが学習するために使うデータのまとまりです。 文章生成AIの場合、Web上の文章、書籍、記事、会話文、コードなど、 大量のテキストデータが学習に使われます。

人間が試験勉強をするときに、教科書や問題集を使うのと同じように、 AIもデータセットを使って「言葉の使い方」や「文章のパターン」を学習します。

たとえで理解

データセットは、AIにとっての 教科書・参考書・問題集のセット のようなものです。 良い教材で学ぶほど理解が深まりやすいように、 AIも学習データの量や質によって性能が変わります。

注意点

データセットに誤った情報、偏った情報、攻撃的な表現などが含まれていると、 AIの出力にもその影響が出る可能性があります。 そのため、学習データの品質はとても重要です。

試験ポイント

データセットは「AIが学習するためのデータの集まり」。 生成AIの性能や偏りに関係する重要語句です。

③ パラメータ

パラメータとは、 AIモデルの内部にある調整用の数値です。 AIは学習を通じて、このパラメータを少しずつ調整し、 より自然な文章や適切な回答を生成できるようになります。

パラメータ数が多いモデルほど、複雑な表現や文脈を扱える可能性が高くなります。 GPT-1、GPT-2、GPT-3、GPT-3.5、GPT-4と進むにつれて、 モデルが大規模化しています。

たとえで理解

パラメータは、料理でいう 味つけを調整する無数のつまみ のようなものです。 塩加減、火加減、香り、食感などを細かく調整することで料理の完成度が上がるように、 AIも大量のパラメータを調整して回答の精度を高めます。

誤解しやすい点

パラメータ数が多ければ必ず性能が高い、というわけではありません。 学習データの質、モデルの設計、調整方法、安全対策なども性能に関係します。

試験ポイント

パラメータは「モデル内部の調整値」。 GPTの変遷では、モデルの大規模化を説明する語句として出やすいです。

④ ファインチューニング

ファインチューニングとは、 すでに学習済みのAIモデルを、特定の目的や用途に合わせて追加で調整することです。

たとえば、一般的な知識を持つAIに対して、 「医療相談向け」「社内FAQ向け」「カスタマーサポート向け」など、 特定分野のデータを追加で学習させることで、その用途に合った回答ができるようにします。

たとえで理解

ファインチューニングは、 一般的な研修を受けた社員に対して、 配属先に合わせた専門研修を行うイメージです。

たとえば、新入社員が基本的なビジネスマナーを学んだあと、 経理部では会計知識、営業部では提案資料の作り方を追加で学ぶようなものです。

試験ポイント

ファインチューニングは 「事前学習済みモデルを特定用途向けに微調整すること」 と覚えましょう。 ChatGPTが対話向けに調整された、という説明と関連します。

⑤ RLHF

RLHFは、 Reinforcement Learning from Human Feedback の略で、日本語では 人間のフィードバックによる強化学習 と訳されます。

AIが出した複数の回答に対して、人間が 「この回答はわかりやすい」 「この回答は危険」 「この回答は指示に合っていない」 などと評価します。 その評価をもとに、AIがより望ましい回答を出せるように調整されます。

たとえで理解

RLHFは、先生が生徒の作文を添削するようなものです。 生徒が作文を書く → 先生が良い点・悪い点を指摘する → 生徒が次はより良い作文を書く、 という流れに似ています。

RLHFの流れ

  1. AIが回答を生成する。
  2. 人間が回答の良し悪しを評価する。
  3. その評価をもとに、AIが望ましい回答の傾向を学習する。
  4. より自然で安全な回答を出しやすくなる。

試験ポイント

RLHFは、InstructGPTやGPT-3.5の説明と関連して出やすい重要語句です。 「人間の評価を使って、AIの出力を改善する仕組み」と押さえましょう。

⑥ アライメント（Alignment）

アライメントとは、 AIの出力や行動を、人間の意図・価値観・安全性に合うように調整することです。

高性能なAIであっても、利用者の意図と違う回答をしたり、 危険な内容を出力したりする可能性があります。 そのため、AIが「人間にとって望ましい方向」に動作するように整えることが重要になります。

たとえで理解

アライメントは、車のハンドルの向きを調整することに似ています。 エンジンが強力でも、進む方向がずれていたら危険です。 AIも高性能であるほど、 人間の目的に沿った方向へ調整すること が大切になります。

RLHFとの関係

RLHFは、アライメントを実現するための代表的な方法の一つです。 つまり、アライメントは「目標・考え方」、 RLHFは「そのための具体的な手法」と整理できます。

試験ポイント

アライメントは 「AIを人間の意図や価値観に合わせること」 です。 安全性・倫理・望ましい回答と関連して理解しましょう。

⑦ ハルシネーション（Hallucination）

ハルシネーションとは、 AIが不正確な情報や存在しない情報を、 あたかも正しい情報であるかのように生成してしまう現象です。

「Hallucination」は本来「幻覚」という意味です。 AIが事実ではない内容をもっともらしく言ってしまうため、 生成AIを使ううえで特に注意が必要な用語です。

具体例

  • 存在しない法律名を作って説明する。
  • 実在しない本や論文を引用する。
  • 人名、会社名、日付を間違える。
  • 最新情報を知らないのに、知っているように答える。

注意点

ハルシネーションは、モデルの性能が向上しても完全にはなくなりません。 特に、法律・医療・金融・試験情報・最新ニュースなどでは、 必ず一次情報や信頼できる資料で確認する必要があります。

試験ポイント

ハルシネーションは 「誤情報を正しいように生成すること」 です。 生成AIのリスクとして非常に問われやすい用語です。

⑧ マルチモーダル

マルチモーダルとは、 テキスト、画像、音声、動画など、 複数の種類のデータを扱えるAIの仕組みや性質を指します。

「モーダル」とは、AIの分野では 入力や出力の形式・情報の種類 のことです。 文章だけを扱うAIは単一モーダル、 文章と画像、音声などを組み合わせて扱えるAIはマルチモーダルです。

具体例

  • 画像を見せて「この写真の内容を説明して」と質問する。
  • 音声で質問して、音声で回答してもらう。
  • 文章と画像を組み合わせて広告案を作る。
  • グラフ画像を読み取って、内容を文章で説明する。

オムニモーダルとの違い

マルチモーダルは、複数の種類のデータを扱えることです。 一方、GPT-4oの説明で出てくる オムニモーダルは、 テキスト・画像・音声などをより統合的、自然、シームレスに扱うイメージです。

試験ポイント

マルチモーダルは 「テキストだけでなく、画像・音声・動画など複数種類のデータを扱えること」 と覚えましょう。 GPT-4、GPT-4o、画像生成AI、動画生成AIの理解にもつながります。

重要語句の最終チェック

用語 一言でいうと
自然言語処理（NLP） 人間の言葉をAIが処理する技術
データセット AIが学習するためのデータの集まり
パラメータ AIモデル内部で調整される数値
ファインチューニング 学習済みモデルを特定用途向けに微調整すること
RLHF 人間の評価を使ってAIの出力を改善する方法
アライメント AIを人間の意図や価値観に合わせること
ハルシネーション 誤情報を正しいように生成すること
マルチモーダル テキスト・画像・音声など複数種類のデータを扱えること

5. GPT-1〜GPT-3.5までの説明

① GPT-1：GPTシリーズの出発点

GPT-1は、2018年に登場したGPTシリーズの初期モデルです。 GPTという名前のとおり、 Generative Pre-trained Transformer の考え方を使っています。

まず大量の文章を読ませて、 「この文章の次には、どのような単語が来やすいか」を学習させます。 このように、あらかじめ大量のデータで学習しておくことを 事前学習といいます。

イメージ

GPT-1は、たくさんの文章を読んで 「言葉のつながり方」や「文章の流れ」 を学んだAIです。 たとえば、「今日はとても天気が」という文があれば、 次に「よい」「悪い」「いい」などが来やすいと予測します。

押さえ方

GPT-1は、現在のChatGPTのように自然な会話をするというより、 GPT方式の有効性を示した出発点です。 「大量の文章で事前学習し、その知識をさまざまな言語処理に活用する」という流れがここから始まりました。

試験ポイント

GPT-1は 「GPTシリーズの出発点」「事前学習の考え方を活用した初期モデル」 と覚えましょう。

② GPT-2：文章生成能力が大きく向上

GPT-2は、2019年に登場したモデルです。 GPT-1よりも大規模になり、文章の続きをより自然に生成できるようになりました。

GPT-2では、短い入力文を与えると、その続きを長く自然に書く能力が注目されました。 たとえば、ニュース記事の書き出しや物語の冒頭を入力すると、 それに続く文章をもっともらしく作成できます。

イメージ

GPT-1が「文章の流れを学び始めたAI」だとすると、 GPT-2は 「文章の続きをかなり自然に書けるようになったAI」 です。

文章生成能力が上がったことで、便利さだけでなく、 偽ニュースやスパムなどへの悪用リスクも話題になりました。

注意して説明したい点

GPT-2は高性能化したことで、 「AIが自然な文章を作れることには、社会的な影響やリスクもある」 という点が強く意識されるようになったモデルです。

試験ポイント

GPT-2は 「文章生成能力の向上」と「悪用リスクへの注目」 をセットで覚えると理解しやすいです。

③ GPT-3：一気に大規模化し、できることが広がった

GPT-3は、2020年に登場した大規模言語モデルです。 パラメータ数は約1,750億とされ、GPT-2から大きく規模が拡大しました。

GPT-3の大きな特徴は、文章生成だけでなく、 要約、翻訳、質問応答、文章分類、コード作成など、 さまざまな自然言語処理タスクに対応しやすくなったことです。

Few-shot learning（少数例からの学習）のイメージ

GPT-3では、プロンプトの中に少しだけ例を入れると、 その例を見て似た形式で答えやすくなりました。

たとえば、 「りんご → apple」「みかん → orange」と例を見せてから 「ぶどう → ?」と入力すると、 「grape」のように形式を推測して答えるイメージです。

誤解しやすい点

GPT-3は非常に高性能ですが、 人間のように事実を完全に理解しているわけではありません。 学習したパターンをもとに、もっともらしい文章を作るため、 誤情報を自然な文章で出してしまうこと があります。

試験ポイント

GPT-3は 「大規模化」「約1,750億パラメータ」「少数例からの対応力」 が重要です。

④ InstructGPT：人間の指示に従いやすくしたモデル

InstructGPTは、GPT-3をもとに、 人間の指示により適切に従うよう調整したモデルです。

GPT-3は文章生成能力が高い一方で、 利用者の指示どおりに答えなかったり、 必要以上に長い文章を出したり、 安全でない内容を出してしまったりすることがありました。

イメージ

GPT-3が「文章を書く力が高い人」だとすると、 InstructGPTは 「相手の依頼を聞いて、依頼に合う形で答える練習をした人」 です。

RLHFとの関係

InstructGPTでは、 RLHF という方法が重要です。 AIが出した回答を人間が評価し、 「この回答はよい」「この回答は指示に合っていない」 というフィードバックをもとに、より望ましい回答へ調整します。

試験ポイント

InstructGPTは 「GPT-3を人間の指示に従いやすく調整したモデル」 です。 RLHFやアライメントの説明とセットで押さえましょう。

⑤ GPT-3.5：ChatGPT登場の土台

GPT-3.5は、GPT-3をさらに改良したモデル群です。 ChatGPTの初期版は、このGPT-3.5系のモデルをもとに対話向けに調整されました。

GPT-3.5では、文章生成だけでなく、 会話の流れを踏まえた応答、追加質問への対応、要約、説明、コード作成などがより使いやすくなりました。

ChatGPTにつながるポイント

これまでのGPTは「文章を生成するAI」という印象が強かったのに対し、 GPT-3.5をもとにしたChatGPTでは、 人と会話しながら作業を進めるAI として利用しやすくなりました。

たとえば、最初に質問し、その回答に対して 「もう少し短くして」「初心者向けにして」「表にして」 と追加で指示できるような使い方です。

注意点

GPT-3.5は対話が得意になりましたが、 ハルシネーションがなくなったわけではありません。 事実確認が必要な内容では、必ず信頼できる情報源で確認する必要があります。

試験ポイント

GPT-3.5は 「ChatGPT登場の土台」「対話向けに使いやすくなったモデル」 と覚えましょう。

GPT-1〜GPT-3.5までの流れを一言で整理

モデル 一言でいうと 授業での説明例
GPT-1 GPTシリーズの出発点 大量の文章で事前学習し、言葉のつながりを学ぶ考え方を示した。
GPT-2 自然な文章生成が大きく向上 文章の続きを長く自然に書けるようになり、悪用リスクも注目された。
GPT-3 一気に大規模化 プロンプトだけで要約・翻訳・質問応答などに対応しやすくなった。
InstructGPT 指示に従いやすく調整 人間の評価を使って、より望ましい回答を出すように調整した。
GPT-3.5 ChatGPTの土台 会話形式で使いやすくなり、ChatGPTの初期版につながった。

ここまでの大きな流れ

GPT-1からGPT-3までは、主に モデルの大規模化と文章生成能力の向上 が大きなポイントです。

InstructGPTとGPT-3.5では、 ただ文章を作るだけでなく、 人間の指示に従いやすい対話型AIへ近づいたこと が重要です。

6. GPT-4で特に押さえる性能向上

ハルシネーションの減少

ハルシネーションとは、AIが不正確または誤った情報を、 あたかも正しい情報のように生成することです。

GPT-4ではGPT-3.5より減少したとされますが、 完全になくなったわけではありません。

マルチモーダル

モーダルは、AIでは「入力方法・情報の種類」という意味で使われます。 テキスト、画像、音声、動画などを複数扱えるのがマルチモーダルです。

多言語の文章生成精度の向上

GPT-3.5では英語に比べて日本語などの精度が低く、不自然さや誤りが見られることがありました。 GPT-4では日本語を含む多くの言語で出力精度が改善された点が教科書で示されています。

注意：ハルシネーション対策

  • AIの回答をそのまま信用しない。
  • 法律、医療、金融、試験範囲、最新情報は必ず確認する。
  • 「もっともらしい文章」と「正しい情報」は別物と考える。

7. ChatGPTのその後の進化（表の項目を詳しく解説）

この章での見方

GPT-4以降は、単に「文章がうまくなった」だけではありません。 画像・音声を扱う、 じっくり考える、 道具を使って作業する、 コード開発を支援する というように、できることの方向性が広がっています。

試験対策では、モデル名を丸暗記するよりも、 「何を強化したモデル・機能なのか」をセットで覚えることが大切です。

Code Interpreter：計算・分析・ファイル処理を手伝う機能

Code Interpreterは、ChatGPTがPythonというプログラミング言語を使って、 自分でコードを書き、実行し、結果をもとに回答できる機能です。

通常のChatGPTは文章で説明することが中心ですが、Code Interpreterでは、 実際に計算したり、表データを読み込んだり、グラフを作成したりできます。 そのため、データ分析・数学計算・ファイル処理に向いています。

できること 具体例
データ分析 ExcelやCSVを読み取り、合計、平均、割合、相関などを計算する。
グラフ作成 売上推移の折れ線グラフ、構成比の円グラフ、比較用の棒グラフを作る。
数学計算 複雑な計算や統計処理を、実際にコードで確認しながら行う。
ファイル処理 ファイルを読み込む、整形する、別形式に変換するなどの作業を行う。

たとえで理解

Code Interpreterは、ChatGPTの中にいる 計算と分析が得意なアシスタントです。 文章で考えるだけでなく、実際に電卓やExcelのような道具を使って確認してくれるイメージです。

試験ポイント

Code Interpreterは、AIモデルの名前というより、 ChatGPTがコードを実行して分析・計算を行うための機能として押さえましょう。

GPTs：目的別に作るオリジナルChatGPT

GPTsは、ユーザーが目的に合わせてカスタマイズできるChatGPTです。 たとえば、授業用の教材作成GPT、社内マニュアル回答GPT、旅行計画GPTなど、 特定の用途に合わせた「専用アシスタント」を作るイメージです。

GPTモデルそのものを新しく作るというより、 既存のChatGPTに役割・指示・参照資料などを設定して、使いやすくする機能 と考えるとわかりやすいです。

設定できるもの 説明
役割・口調 先生風、ビジネス文書添削風、初心者向け講師風など、振る舞いを決める。
参照ファイル マニュアル、教材、商品資料などを入れて、その内容をもとに回答させる。
外部サービス連携 APIなどと連携して、情報取得や操作を行えるようにする。

混同注意：GPTモデルとGPTs

GPTモデルは、ChatGPTの土台となるAIそのものです。 一方、GPTsは、その土台を使って目的別に作るカスタム版ChatGPTです。

GPT-4o：文章・画像・音声を自然につなぐモデル

GPT-4oは、2024年5月に発表されたモデルです。 「o」は omni を表し、「すべての」「包括的な」という意味があります。

それまでのChatGPTは、文章を中心にしたやり取りが主でした。 GPT-4oでは、テキスト・画像・音声をより自然に扱えるようになり、 画像を見て説明したり、音声で会話したりする方向へ進化しました。

何がすごいのか

  • 文章だけでなく、画像や音声も扱える。
  • 音声会話の反応が速く、会話に近い使い方ができる。
  • 画像の内容を読み取り、説明や分析に活用できる。

授業でのたとえ

GPT-4oは、文字だけでなく、写真を見たり、声を聞いたりしながら対応できる 多機能な先生のようなものです。

試験ポイント

GPT-4oは、オムニモーダルが重要語句です。 「テキスト・画像・音声を統合的に扱う」と覚えましょう。

リーズニングモデル：GPT-o1・GPT-o3・GPT-o4

リーズニングモデルは、すぐに答えることよりも、 問題を段階的に検討し、より正確に答えることを重視したモデルです。

通常のモデルが「すばやく返答するアシスタント」だとすると、リーズニングモデルは 難しい問題をじっくり考えてから答えるアシスタントです。 数学、プログラミング、論理問題、複雑な手順の整理などに向いています。

表記についての注意

教材や表では「GPT-o1」「GPT-o3」「GPT-o4」と書かれることがあります。 公式情報では、OpenAI o1、OpenAI o3、o4-miniのような表記が使われることがあります。 試験対策では、表記の違いよりも、推論を重視するoシリーズとして理解することが大切です。

モデル わかりやすい説明 覚え方
GPT-o1 回答前により多くの時間をかけて考えるモデル。 数学、科学、コード、複雑な推論問題などで力を発揮する。 「まず、じっくり考えるAI」。
GPT-o3 o1の考え方をさらに発展させた高性能なリーズニングモデル。 複数の条件を整理する問題、コード設計、画像やグラフを含む分析などに強い。 「より難しい問題を深く考えるAI」。
GPT-o4
※公式では主にo4-miniなど		 小型で高速・効率的なリーズニングモデルとして説明されることが多い。 数学、コーディング、画像を含む課題に対して、速さと推論力のバランスを取る。 「考える力を、軽く速く使うAI」。

図解イメージ

通常モデル：質問 → すばやく回答
リーズニングモデル：質問 → 条件を整理 → 手順を考える → 必要なら道具を使う → 回答

試験ポイント

oシリーズは、推論・数学・コード・複雑な問題解決に強いモデルとして押さえます。 GPT-4oの「オムニモーダル」と、oシリーズの「リーズニング」を分けて覚えると混同しにくいです。

GPT-4.1：コーディング・指示追従・長文処理を強化

GPT-4.1は、GPT-4系をさらに実務向けに改良したモデルとして理解するとよいです。 特に、コーディング、指示に正確に従う力、 長い文章や大きなコードを扱う力が強化された点がポイントです。

強化された点 説明
コーディング プログラムの作成、修正、バグの発見、仕様に沿った実装を支援しやすい。
指示追従 ユーザーが指定した条件や形式に、より正確に合わせやすい。
長文・長いコード 長い資料や大規模なコードを読み取り、内容を整理しやすい。

たとえで理解

GPT-4.1は、ざっくりした相談よりも、 「この仕様どおりにコードを書いて」「この条件に合わせて修正して」のような 実務の細かい指示に対応する作業者に近いイメージです。

GPT-5：速さと深い思考を使い分ける方向へ

GPT-5は、2025年に発表された重要モデルです。 教材では「推論力と速度の進化」として押さえるとわかりやすいです。

GPT-5のポイントは、すべての質問に同じ答え方をするのではなく、 簡単な質問にはすばやく答え、難しい質問にはより深く考えるというように、 状況に応じて応答の仕方を切り替える方向に進化したことです。

得意な場面

  • 複雑な文章作成や要約
  • 調査・分析・問題解決
  • コーディングや仕様整理
  • 画像を含む理解や説明

GPT-5 Thinkingのイメージ

GPT-5 Thinkingは、より深く考える必要がある課題で使うモードです。 難しい問題を、手順を整理しながら検討するイメージです。

注意点

性能が上がっても、ハルシネーションが完全になくなるわけではありません。 試験情報、法律、医療、金融、最新ニュースなどは、必ず公式情報や信頼できる資料で確認する必要があります。

8. 関連サービス・機能の詳しい説明

ここで押さえるポイント

Sora、Operator、Codex、Image Generationは、GPTモデルそのものというより、 生成AIを使って何をするサービス・機能なのかで整理するとわかりやすいです。

Sora：文章や画像から動画を作るAI

Soraは、文章や画像をもとに動画を生成するAIです。 「夕焼けの海辺を犬が走っている動画を作って」のように、 文章で場面を指示すると、その内容に合う映像を作るイメージです。

画像生成AIが「1枚の絵や写真」を作るのに対し、Soraは 時間の流れがある映像を作る点が特徴です。 そのため、人物や物体の動き、カメラワーク、場面の変化なども扱います。

たとえで理解

Image Generationが「ポスターやイラストを作るデザイナー」だとすると、 Soraは「短い映像を作る映像クリエイター」です。

試験ポイント

Soraは、動画生成AIとして覚えます。 Image Generationと混同しないように、Sora＝動画と押さえましょう。

Operator：Web画面を操作するAIエージェント

Operatorは、AIがWebブラウザを使い、画面を見ながら、 クリック・入力・スクロールなどの操作を行うAIエージェントです。

普通のChatGPTは「調べ方を教える」「文章で説明する」ことが中心です。 Operatorはそれに加えて、実際にWeb画面を操作して作業を進める点が特徴です。

通常のChatGPT Operator
操作方法を文章で説明する。 画面を見て、クリックや入力などの操作を行う。
ユーザーが自分でWebサイトを操作する。 ユーザーの代わりにWeb上のタスクを実行する。

AIエージェントのイメージ

従来のChatGPTが「質問に答える先生」だとすると、 AIエージェントは「目標を聞いて、必要な手順を考え、道具を使って作業を進める秘書」です。

例：旅行予約を頼むと、検索 → 候補比較 → フォーム入力 → 予約確認という流れを自動で進めるイメージです。

具体例

  • Webページを開いて情報を探す。
  • フォームに必要事項を入力する。
  • 候補を比較して、条件に合うものを探す。
  • 予約や購入の前段階まで作業を進める。

試験ポイント

Operatorは、AIエージェントの例として重要です。 「質問に答えるAI」から、「作業を実行するAI」へ進んだ例と考えましょう。

Codex：ソフトウェア開発を支援するAIエージェント

Codexは、プログラム開発を支援するAIエージェントです。 コードを書くだけでなく、バグ修正、機能追加、テスト、コードベースに関する質問への回答など、 開発作業全体を支援します。

Code Interpreterが「Pythonを実行して分析・計算する機能」なのに対し、Codexは ソフトウェア開発そのものを手伝うエージェントです。

項目 Code Interpreter Codex
主な目的 計算、データ分析、グラフ作成 プログラム開発、バグ修正、機能追加
イメージ 分析担当 開発担当
使う場面 ExcelやCSVを分析したいとき アプリやWebシステムのコードを作りたいとき

試験ポイント

Codexは、ソフトウェア開発支援AIとして覚えます。 Code Interpreterとの違いは、 分析・計算か、開発支援かです。

Image Generation：画像を作るAI

Image Generationは、文章で指示した内容をもとに画像を生成する機能です。 たとえば、「白背景で、初心者向けのAI講座を表すやさしいイラスト」のように指示すると、 そのイメージに合う画像を作ります。

近年の画像生成では、単にきれいな画像を作るだけでなく、 文字入り画像、レイアウト、 既存画像の編集など、実用的な用途にも使われます。

得意なこと

  • 教材用イラストの作成
  • アイコンやバナーの作成
  • 商品のイメージ画像の作成
  • 既存画像の雰囲気変更や補正

注意点

画像内の文字、細かい指の形、正確な図表などは誤りが出る場合があります。 授業や実務で使う場合は、必ず目視で確認しましょう。

試験ポイント

Image Generationは、画像生成AIです。 Soraは動画、Image Generationは画像、と対比して覚えましょう。

名称 何をするものか 混同しやすい点
Sora 文章や画像から動画を生成するAI。 静止画生成ではなく、動画生成AI。
Operator Web画面を見て、クリック・入力・スクロールなどの操作を行うAIエージェント。 単なるチャットではなく、Web上の作業を実行する。
Codex ソフトウェア開発を支援するAIエージェント。 Code Interpreterは分析・計算、Codexは開発支援。
Image Generation 文章や画像をもとに画像を生成・編集する機能。 Soraは動画、Image Generationは画像。
補足

試験シラバスの「GPT-o1・GPT-o3・GPT-o4」に対応して、公式情報ではOpenAI o1、OpenAI o3、o4-miniなどの名称が使われます。GPT-4oの「o（omni）」と、推論モデルのoシリーズは区別しましょう。また、GPT-3.5やGPT-4のパラメータ数は公開されていないため、世代ごとの増加を公開値で確認できるわけではありません。

9. 似た用語の違い

似た用語 違い
GPTモデル と GPTs GPTモデルは土台となるAIモデル。GPTsは目的に合わせて作るカスタム版ChatGPT。
ファインチューニング と RLHF ファインチューニングは用途に合わせた微調整。RLHFは人間の評価を使って望ましい応答を学ばせる手法。
マルチモーダル と オムニモーダル マルチモーダルは、テキスト・画像・音声など複数種類のデータを扱えること。 オムニモーダルは、それらを別々ではなく、より統合的・自然に扱えること。
試験では「オムニモーダル＝マルチモーダルをさらに自然に統合したもの」と覚える。
Code Interpreter と Codex Code Interpreterは、Pythonを実行してデータ分析・計算・グラフ作成を行う機能。 Codexは、バグ修正・機能追加・テストなど、ソフトウェア開発を支援するAIエージェント。
Code Interpreter＝データ分析係、Codex＝プログラム開発係。
Sora と Image Generation Soraは動画生成AI。Image Generationは画像生成AI。

10. 試験で問われやすいポイント

  1. ChatGPTの名前の意味
    Chat＝対話、G＝Generative、P＝Pre-trained、T＝Transformer。
  2. GPT-1 → GPT-2 → GPT-3 → GPT-3.5 → GPT-4 の流れ
    文章生成能力、対話能力、モデル規模、精度が段階的に向上。
  3. InstructGPT・RLHF・アライメント
    人間の指示や価値観に合うように出力を調整する考え方。
  4. ハルシネーション
    AIが誤情報をもっともらしく出すこと。性能向上後も確認が必要。
  5. マルチモーダルとGPT-4o
    テキストだけでなく、画像や音声も扱える方向へ進化。
  6. リーズニングモデル
    GPT-o1、GPT-o3、GPT-o4は、速さよりも推論の質を重視。
  7. AIエージェント
    OperatorやCodexのように、目標を分解し、計画し、ツールを使って実行するAI。

11. まとめ

  • ChatGPTは、自然言語処理モデルを使った対話型AIである。
  • GPTの進化では、文章生成の自然さ、対話能力、推論力、マルチモーダル処理が重要。
  • RLHFは、人間のフィードバックを使ってAIの応答を改善する仕組み。
  • アライメントは、AIの出力を人間の意図や価値観に合わせること。
  • ハルシネーションは、AIが誤情報を正しそうに出す現象。試験でも実務でも重要。
  • GPT-4oはオムニモーダル、GPT-o1/o3/o4はリーズニングモデルとして押さえる。
  • Soraは動画生成、OperatorはWeb操作を行うAIエージェント、Codexはソフトウェア開発支援、Image Generationは画像生成。

最後の確認

試験では、「どのモデルが何を強化したか」「似た用語の違い」「ハルシネーションやRLHFなどの重要語句」が問われやすいです。 年号だけでなく、進化の方向性をセットで覚えましょう。
