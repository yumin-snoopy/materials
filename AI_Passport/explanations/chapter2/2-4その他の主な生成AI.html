本文解説：この節の全体像

生成AIパスポート試験では、ChatGPTだけでなく、ChatGPT以外の主要な生成AIについても概要を理解する必要があります。 この節で特に押さえるのは、Gemini、Claude、Copilot の3つです。

試験ポイント

最初に覚えるべきことは、名前と開発元の対応です。
Gemini = Google DeepMind
Claude = Anthropic
Copilot = Microsoft

3つとも文章生成や質問応答ができますが、試験では「全部同じチャットAI」と覚えるのではなく、 それぞれの立ち位置を区別することが大切です。

1. Gemini の特徴

Gemini は、Google DeepMind が開発する生成AIです。 Google検索、Gmail、Googleドキュメント、Android、クラウドサービスなど、 Googleのさまざまなサービスと関係が深いAIとして理解すると覚えやすくなります。

Geminiを一言でいうと

Geminiは、テキストだけでなく、画像・音声・動画・コードなども扱うことを重視した マルチモーダル型の生成AIです。 「文章だけを読むAI」ではなく、「見たり、聞いたり、読んだり、コードを扱ったりできるAI」と考えるとわかりやすいです。

Gemini の重要キーワード

① Google DeepMind

Geminiの開発元は Google DeepMind です。 試験では、ChatGPTのOpenAI、ClaudeのAnthropic、CopilotのMicrosoftと混同しないことが重要です。

② マルチモーダル

マルチモーダル とは、複数の種類の情報を扱えることです。 ここでいう「モード」とは、情報の形式を意味します。 たとえば、文章、画像、音声、動画、コードなどがそれぞれ異なるモードです。

具体例

画像に写っているグラフを読み取り、その内容を日本語で説明し、さらに表に整理する。 あるいは、資料の画像を見ながら説明文を作り、必要に応じてコードも書く。 このような使い方が、マルチモーダルAIのイメージです。

③ reasoning

reasoning は、AIが答えを出すときに、より深く考える仕組みを指します。 単純な質問には素早く答え、複雑な問題では段階的に考えて答える、というイメージです。

たとえ話

「今日の天気を教えて」のような質問はすぐ答えられます。 一方で、「売上データを見て、原因を分析し、改善策を3つ提案して」のような質問は、 データを読み取り、比較し、原因を考え、提案を作る必要があります。 このように複雑な問題を考える力が reasoning です。

④ Pro・Flash・Nano の違い

Geminiには、用途に応じて複数のモデルがあります。 試験では細かな性能差まで暗記するよりも、名前から役割をイメージできることが大切です。

Gemini Pro

Proは、高度な処理や複雑な作業に向いたモデルです。 文章作成、コード、数学的な処理、長めの分析など、能力の高さを重視する場面で使われます。

Gemini Flash

Flashは、名前の通り、速度や効率を重視するモデルです。 多くの質問にすばやく答える、コストを抑えて大量に処理する、といった場面に向いています。

Gemini Nano

Nanoは、スマートフォンなどの端末上で動作する軽量版として理解します。 クラウドに毎回送らなくても、端末内で一部のAI処理を行えることがポイントです。

試験ポイント

Geminiは、Google DeepMind、マルチモーダル、reasoning、 Pro / Flash / Nano をセットで覚えましょう。

誤解注意

「マルチモーダル」は、単に画像を読み込めるという意味だけではありません。 テキスト・画像・音声・動画・コードなど、複数の形式の情報を扱えるという広い意味です。

2. Claude の特徴

Claude は、Anthropic が開発する生成AIです。 Claudeは、文章の読み書き、要約、推論、長い資料の処理などに強みを持つAIとして紹介されることが多いです。

Claudeを一言でいうと

Claudeは、安全性や丁寧な応答を重視し、長い文書を扱いやすい 文章処理・推論に強い生成AIです。 「長い資料を読ませて、要約や整理をしてもらうAI」と考えるとイメージしやすいです。

Claude の重要キーワード

① Anthropic

Claudeの開発元は Anthropic です。 Anthropicは、安全性を重視したAI開発で知られています。 試験では、ClaudeとAnthropicを結びつけて覚えることが重要です。

② Constitutional AI

Constitutional AI は、AIが一定の原則に基づいて回答を調整する考え方です。 「Constitutional」は「憲法のような」という意味です。 つまり、AIに守るべき原則を与え、それに沿って安全で有用な回答を目指す仕組みと理解します。

たとえ話

学校に校則があると、生徒は「やってよいこと」「やってはいけないこと」を判断しやすくなります。 Constitutional AIも同じように、AIに守るべき原則を与え、危険な回答や不適切な回答を避ける方向に調整します。

③ 「無害・役立つ・正直」

Claudeを理解するうえでは、無害・役立つ・正直という考え方が重要です。 無害とは危険な使い方を助長しないこと、役立つとは利用者の目的に沿って支援すること、 正直とはわからないことを無理に断定しないことです。

④ Haiku・Sonnet・Opus の違い

Claudeには、用途に応じて複数のモデル名があります。 代表的な名前として、Haiku、Sonnet、Opus を押さえましょう。

Claude Haiku

Haikuは、軽量で高速なモデルとして理解します。 すばやい応答や、比較的簡単な作業を効率よく処理する場面に向いています。

Claude Sonnet

Sonnetは、速度と能力のバランスを重視したモデルです。 日常的な文章作成、要約、アイデア出し、分析など、幅広い用途に使いやすい位置づけです。

Claude Opus

Opusは、複雑な推論や高度な文章処理に向いた上位モデルとして理解します。 難しい問題の分析、長い文書の精読、複雑な計画づくりなどに向いています。

⑤ 長大なコンテキスト

コンテキスト とは、AIが回答の手がかりにする文脈や参照情報のことです。一度に扱える情報量の上限は「コンテキストウィンドウ」と呼びます。 Claudeは長い文章や大量の資料を扱う用途でよく説明されます。 長大なコンテキストを扱えると、長いPDF、仕様書、議事録、契約書のような文書をまとめて処理しやすくなります。

具体例

50ページの会議資料を読み込ませて、「重要な論点を5つにまとめて」 「リスクだけ抜き出して」「次回会議のアジェンダを作って」と依頼するような使い方です。

⑥ Artifacts

Artifacts は、Claudeで文書やコードなどの成果物を別画面のように表示しながら、 生成・編集できる機能として理解します。 チャットでやり取りするだけでなく、作成中の文章やコードを確認しながら修正しやすい点が特徴です。

具体例

Claudeに「授業用のHTML資料を作って」と頼むと、チャットの返答だけでなく、 HTMLファイルのような成果物を画面上で確認しながら編集できるイメージです。

試験ポイント

Claudeは、Anthropic、Constitutional AI、 無害・役立つ・正直、Haiku / Sonnet / Opus、 長大なコンテキスト、Artifacts を押さえましょう。

誤解注意

Claudeは「安全性を重視するから何もできないAI」という意味ではありません。 実際には、文章生成、要約、分析、コード作成など多くの作業ができます。 ただし、危険な内容や不適切な使い方には慎重に対応する設計だと理解しましょう。

3. Copilot の特徴

Copilot は、Microsoft が展開するAIブランドです。 Word、Excel、Outlook、Teams、PowerPoint、GitHub、セキュリティ製品など、 Microsoftのサービスに組み込まれて作業を支援します。

Copilotを一言でいうと

Copilotは、単独のAIモデル名というより、Microsoft製品の中で利用者の作業を助ける AIアシスタント機能・サービス群です。 「仕事中に横で手伝ってくれる副操縦士」というイメージで覚えましょう。

Copilot の重要キーワード

① Microsoft

Copilotの提供元は Microsoft です。 試験では、Copilotを「MicrosoftのAI」として覚えることが第一歩です。

② Microsoft 365との連携

Copilotは、Word、Excel、Outlook、Teams、PowerPointなど、 Microsoft 365のアプリと連携して使われます。 つまり、チャットで質問するだけでなく、普段の業務画面の中でAIが支援してくれる点が特徴です。

具体例
  • Word：文章の下書き、書き換え、要約を支援する
  • Excel：表の分析、傾向の説明、関数の提案を支援する
  • Outlook：メールの要約、返信文の作成を支援する
  • Teams：会議内容の要約、決定事項やタスクの整理を支援する
  • PowerPoint：資料構成やスライド案の作成を支援する

③ Copilot Studio

Copilot Studio は、自社の業務に合わせたAIアシスタントを作るための仕組みです。 たとえば、社内FAQに答えるAI、問い合わせ対応を支援するAI、業務手順を案内するAIなどを作るイメージです。

具体例

会社の人が「経費精算の方法を教えて」と聞いたときに、 社内ルールに基づいて回答するAIを作る。 これがCopilot Studioのような仕組みで実現できる用途です。

④ GitHub Copilot

GitHub Copilot は、プログラミングを支援するCopilotです。 コードの候補を出したり、エラーの原因を考えたり、関数の作成を補助したりします。

具体例

プログラマーが「この処理をPythonで書きたい」と考えたとき、 GitHub Copilotがコードの候補を提案してくれます。 自動車の運転でいうと、運転そのものを完全に任せるのではなく、 横で道案内や操作補助をしてくれる存在に近いです。

⑤ Security Copilot

Security Copilot は、セキュリティ業務を支援するCopilotです。 セキュリティ担当者が脅威を調査したり、ログを分析したり、対応方針を整理したりする作業を補助します。

⑥ Copilot+ PC

Copilot+ PC は、AI機能を活用することを前提としたPCのカテゴリとして理解します。 PC上でAIを使った検索、要約、画像処理などを行いやすくする考え方と結びつきます。

試験ポイント

Copilotは、Microsoft、Microsoft 365、 Word・Excel・Outlook・Teams、 Copilot Studio、GitHub Copilot、 Security Copilot を関連づけて覚えましょう。

誤解注意

Copilotは、GeminiやClaudeのように単一のモデル名として覚えるよりも、 Microsoft製品に組み込まれたAI支援機能・サービス群として理解するのが重要です。

重要語句の補足説明

用語1マルチモーダル

マルチモーダルとは、テキスト、画像、音声、動画、コードなど、複数の情報形式を扱えることです。 Geminiを説明するときに特に重要な用語です。

用語2トークン

トークンとは、AIが文章を処理するときの単位です。 日本語では、1文字ずつではなく、文字の一部や意味のまとまりとして分割されることがあります。

用語3コンテキスト

コンテキストとは、AIが回答の手がかりにする文脈や参照情報のことです。一度に扱える情報量の上限は「コンテキストウィンドウ」と呼びます。 コンテキストウィンドウが大きいほど、長い資料や大量の会話履歴を踏まえて回答しやすくなります。

用語4reasoning

reasoningは、AIが答えを出す前に、より深く考える仕組みを指します。 簡単な質問では短く考え、複雑な問題では段階的に推論するイメージです。

用語5Artifacts

Artifactsは、Claudeで文書やコードなどの成果物を確認しながら作成・編集しやすくする機能です。 「チャットの返答」だけでなく、「完成物を横に表示して作業する」イメージです。

用語6Copilot

Copilotは「副操縦士」という意味です。 利用者の代わりにすべてを行うのではなく、利用者の作業を横で支援するAIという意味で使われます。
