# Excel フラッシュフィル練習

## 概要

架空の氏名とメールアドレスを使い、入力例から規則を見つけるフラッシュフィルを練習するExcel教材です。

## 主な機能

- 氏名の姓・名を分ける練習
- Ctrl+E とデータタブからの操作
- メールアドレスのユーザー名を取り出す追加課題

## 使い方

[練習用ブック](flash_fill_practice.xlsx)をExcelで開き、見本の下のセルを選び Ctrl+E、または［データ］→［フラッシュ フィル］を使います。

## 起動・体験

[練習用ブック](flash_fill_practice.xlsx)をダウンロードしてMicrosoft Excelで開いてください。

## 使用技術

Excel（.xlsx）

## ライセンス・外部ライブラリ

外部ライブラリは使用していません。この教材自体のライセンスは明示されていません。
