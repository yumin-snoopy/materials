# Excel プルダウンリスト練習

## 概要

架空の注文管理表で、入力候補を選べるプルダウンリストを練習するExcel教材です。「練習用」と「完成見本」のシートがあります。

## 主な機能

- 注文管理表の練習用データ
- 完成見本での入力規則の確認

## 使い方

[練習用ブック](Excel_プルダウンリスト_注文管理サンプル.xlsx)をExcelで開き、「練習用」でリスト作成を試します。「完成見本」と見比べてください。

## 起動・体験

[練習用ブック](Excel_プルダウンリスト_注文管理サンプル.xlsx)をダウンロードしてMicrosoft Excelで開いてください。

## 使用技術

Excel（.xlsx）

## ライセンス・外部ライブラリ

外部ライブラリは使用していません。この教材自体のライセンスは明示されていません。
