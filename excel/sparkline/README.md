# Excel スパークライン練習

## 概要

架空の焼き菓子店の月別販売データで、推移を小さなグラフで示すスパークラインを練習するExcel教材です。

## 主な機能

- 4～9月の販売数データ
- 練習用と完成例のシート
- 販売数量合計・売上金額の計算練習

## 使い方

[練習用ブック](焼き菓子店_月別販売データ_スパークライン練習.xlsx)をExcelで開き、「練習用」のJ列に折れ線スパークラインを作成します。K列・L列も計算し、「完成例」と比べます。

## 起動・体験

[練習用ブック](焼き菓子店_月別販売データ_スパークライン練習.xlsx)をダウンロードしてMicrosoft Excelで開いてください。

## 使用技術

Excel（.xlsx）

## ライセンス・外部ライブラリ

外部ライブラリは使用していません。この教材自体のライセンスは明示されていません。
