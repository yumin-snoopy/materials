# ⑥ VBAエキスパート BASIC 総合問題30問

VBAエキスパートBASICの選択式練習問題を、スマートフォンでも学習しやすいWeb形式にした教材です。

## Webアプリ

https://yumin-snoopy.github.io/materials/vba_statement_practice_06/

## 主な機能

- 選択式問題（30問）
- 単一正解と複数正解に対応
- 正解・不正解の判定と解説
- 得点、進捗、問題ナビ、フィルター
- スマートフォン対応とQRコード表示
- 前後の問題集と教材一覧への移動

## ファイル構成

- `index.html`：読み取りにくくした最小構成の画面と共通ファイルの読み込み
- `questions.js`：この問題集の問題データ
- `../vba_statement_common/`：共通のデザイン、採点処理、QRコード処理
