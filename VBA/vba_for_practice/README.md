# VBA FOR文 読み解き練習 BASIC

## 概要

For・Nextの回数、Step、Ifとの組み合わせや入れ子を読み解く全10問の教材です。

## 主な機能

- 10問の選択式練習
- 回答の判定・解説・得点表示
- 問題ナビ・フィルター・QRコード表示

## 使い方

開始値・終了値・Stepを確認し、繰り返しごとの変数の値を追って答えます。回答後の解説で確認します。

## 起動・体験

[**VBA FOR文 読み解き練習 BASICを開く**](https://yumin-snoopy.github.io/materials/VBA/vba_for_practice/)

## 使用技術

HTML・CSS・JavaScript
