# VBA エキスパート 練習問題④

## 概要

VBAエキスパートBASICのコードを読む選択式教材です。セルのコピー、表示形式、範囲指定、シート追加を扱い、全10問に挑戦できます。

## 主な機能

- 選択式の練習問題 10問
- 回答の判定・解説・得点と進捗の表示
- 問題の切り替え・回答のリセット・ページのQRコード表示

## 使い方

問題を選んでVBAコードを読み、答えを選択します。判定と解説を確認しながら次の問題へ進みます。
