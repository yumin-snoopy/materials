# VBAステートメント問題集の共通ファイル

## 概要

VBA練習問題①〜⑩で使う画面・採点・デザインの共通部品です。このフォルダだけでは問題画面は起動しません。

## 主な機能

- 問題表示と単一・複数正解の判定
- 得点・進捗・問題ナビ・QRコード表示
- 画面の共通デザイン

## 使い方

[VBA教材一覧](../README.md)から問題集を選んで開いてください。各問題の内容は、それぞれの `questions.js` にあります。

## 起動・体験

単独の起動ページはありません。[VBA教材一覧](../README.md)から各問題集を開いてください。

## 使用技術

HTML・CSS・JavaScript
