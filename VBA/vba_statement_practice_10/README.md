# ⑩ VBAエキスパート BASIC 練習問題

## 概要

VBAエキスパートBASICのコードを読む選択式教材です。VBAエキスパートBASICの総合的なコード読解を扱い、全20問に挑戦できます。

## 主な機能

- 選択式の練習問題 20問
- 回答の判定・解説・得点と進捗の表示
- 問題の切り替え・回答のリセット・ページのQRコード表示

## 使い方

問題を選んでVBAコードを読み、答えを選択します。判定と解説を確認しながら次の問題へ進みます。

## 起動・体験

[**⑩ VBAエキスパート BASIC 練習問題を開く**](https://yumin-snoopy.github.io/materials/VBA/vba_statement_practice_10/)

HTML・CSS・JavaScript
