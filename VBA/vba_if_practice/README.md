# VBA IF文 読み解き練習 BASIC

## 概要

If・ElseIf・ElseやAnd・Orを使う条件分岐を読み解く全10問の教材です。

## 主な機能

- 10問の選択式練習
- 回答の判定・解説・得点表示
- 問題ナビ・フィルター・QRコード表示

## 使い方

VBAコードの条件を順番に確かめ、実行される分岐を選びます。回答後の解説で考え方を確認します。

## 起動・体験

[**VBA IF文 読み解き練習 BASICを開く**](https://yumin-snoopy.github.io/materials/VBA/vba_if_practice/)

## 使用技術

HTML・CSS・JavaScript
