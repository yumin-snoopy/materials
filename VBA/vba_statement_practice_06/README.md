# ⑥ VBAエキスパート BASIC 総合問題30問

## 概要

VBAエキスパートBASICのコードを読む選択式教材です。マクロ記録、セル操作、ブック操作を含む総合問題を扱い、全30問に挑戦できます。

## 主な機能

- 選択式の練習問題 30問
- 回答の判定・解説・得点と進捗の表示
- 問題の切り替え・回答のリセット・ページのQRコード表示

## 使い方

問題を選んでVBAコードを読み、答えを選択します。判定と解説を確認しながら次の問題へ進みます。
