VBA IF文 読み解き練習 BASIC

変数の値を見て、If / ElseIf / Else のどの分岐が実行されるかを選ぶ10問です。And / Or を含む条件は、1つずつ True / False に分解して読みます。

現在の得点 0 / 10

読み方の型

  • If から順番に条件を見る
  • 最初に True になった分岐だけ実行
  • ElseIf は前の条件が False のときだけ確認
  • Else はどれも True でないときに実行

And / Or のコツ

  • And は両方 True で True
  • Or はどちらか True で True
  • VBAでは And が Or より先に評価される
