# VBA IF文 読み解き練習

VBAの `If` / `ElseIf` / `Else`、`And`、`Or` の読み方を練習するWebアプリです。

## Webアプリ

以下のURLから利用できます。

https://yumin0116snoopy-spec.github.io/vba-if-practice/

## 主な機能

- 選択式の練習問題
- 正解・不正解の判定
- 解説と得点の表示
- 学習進捗の表示
- 問題フィルター
- 問題ナビ
- 回答のリセット
- スマートフォン対応

## 利用方法

上記のWebアプリURLへアクセスし、各問題の回答を選択してください。
